## 1. 시스템 개요

**Domo**는 갤러리 접근이 어려운 **글로벌 신진 미술 작가·미대생**과 전 세계 **컬렉터·후원자**를 직접 연결하는 통합형 소셜 거래 플랫폼이다.

작가 한 명이 다음 네 가지 행위를 **하나의 서비스 안에서** 수행할 수 있도록 설계되었다:

| 영역 | 역할 | 비교 대상 |
|---|---|---|
| **소셜 네트워크** | 작품 피드, 좋아요, 댓글, 팔로우, 학교·장르·국가별 커뮤니티 | Instagram |
| **후원(Patronage)** | 1,000원 단위 마이크로 후원 (일회성·월 정기) | Patreon |
| **경매·즉시구매** | 영국식 오름경매 + 즉시구매(Buy-now), 차순위 자동 이전 | Saatchi Art |
| **창작 과정 공유** | 사진·영상·타임랩스 업로드, 외부 임베드(YouTube/Vimeo 등) | YouTube + Behance |

운영 도메인 전략은 `domo.tuzigroup.com`(웹) / `api.domo.tuzigroup.com`(API) / `admin.domo.tuzigroup.com`(관리자) / `cdn.domo.tuzigroup.com`(미디어)로 분리되어 있으며, 한국·영어 다국어와 다중 통화(KRW·USD)를 기본 지원한다.

## 2. 시스템 목적

### 2.1 해결하려는 문제

| 문제 | 현황 | Domo의 답 |
|---|---|---|
| 신진 작가의 **글로벌 진출 장벽** | 갤러리 입점·해외 전시 비용은 작가 1인이 부담 불가 | 무료 가입 + 글로벌 노출 + 결제·정산 인프라 제공 |
| 후원의 **심리적·금전적 진입장벽** | 기존 후원/투자는 단위가 큼(수만~수백만원) | 1 블루버드 = 1,000원 — 1잔의 커피값으로 후원 가능 |
| 신진 작품 시장의 **가격 디스커버리 부재** | 가치 평가 기준이 불투명, 컬렉터 진입 부담 | 경매를 통해 시장이 가격을 결정 + 즉시구매 옵션 병행 |
| 갤러리·학교·후원사의 **작가 발굴·평가 도구 부재** | 추천·랭킹·트렌드 데이터가 산재 | (로드맵) 거래·후원 활동 기반 **AI 시대 작가 인덱스** 산출 |

### 2.2 그로스해킹 깔대기 전략

```
SNS 사용자 (무료, 진입장벽 0)
   ↓
후원자 (1,000원~)
   ↓
컬렉터 (경매·즉시구매)
   ↓
B2B 파트너 (학교·갤러리·후원사 — 리포트 구독)
```

- 사용자 풀이 충분히 커진 뒤 **전환 깔대기로 매출**을 만든다는 그로스해킹 원칙을 시스템 설계 단계부터 반영
- 진입 단계마다 **다음 단계로의 전환 트리거**(예: 후원 → 컬렉터 전환 시 추천 경매 노출)를 데이터 모델에 내재화

### 2.3 타깃 시장

| 우선 시장 | 근거 |
|---|---|
| **동남아·남미·동유럽** 신진 작가 | 갤러리 인프라 부족, 인구 대비 미술 인구 비중 빠르게 성장, 디지털 친화 |
| 한국·일본·유럽 등 선진국 **미대생·졸업 5년 이내 작가** | "졸업 후 갤러리 입점 전" 공백기를 메우는 포지셔닝 |
| 글로벌 **신진 작품 컬렉터** | 12만 원~3,000만 원대 신진 시장에 합리적으로 접근 가능한 채널 부재 |

## 3. 시스템의 특징

### 3.1 구현된 핵심 기능 (Phase 0–4 누적, 매칭률 96–97%)

| 분류 | 기능 | 상태 |
|---|---|:---:|
| **콘텐츠** | SNS 피드(장르·테마·인기·최신 정렬), 사진·영상 업로드, 외부 임베드(YouTube/Vimeo), 좋아요·댓글·팔로우, 검색, Explore | ✅ |
| **작가 운영** | 작가 신청·심사(포트폴리오·자기소개·학교 정보), 관리자 승인/반려, 작가 프로필 뱃지(Student/Emerging/Recommended/Popular) | ✅ |
| **후원** | 블루버드 일회성 후원(1BB=1,000원, 익명 옵션, 공개범위 4단계), 월 정기 후원(`cancel_at_period_end` 정책) | ✅ |
| **거래** | 영국식 오름경매 + 즉시구매(Buy-now) 병행, 차순위 자동 이전(최대 2회 라운드), 미결제 자동 취소 + 재경매 | ✅ |
| **결제·정산** | 실 Stripe / Mock 어댑터 동시 운영, KYC(Toss·Stripe Identity), 주간·월간 정산 배치 + 관리자 승인·지급 | ✅ |
| **모더레이션** | 콘텐츠 신고·이의제기 플로우, 3진 아웃 경고 시스템, 디지털 아트 수동 판독 큐 | ✅ |
| **컴플라이언스** | GDPR(soft delete, 데이터 export, 쿠키 동의, 정책 버전 추적), 미성년자 보호자 동의(GDPR-K 16 / COPPA 13 / 한국 14), 약관·개인정보 버전 동의 기록 | ✅ |
| **운영** | 매출 대시보드(GMV·플랫폼 수수료·후원 합계·구독 MRR·경매·Buy-now), 신고 처리 큐, Rate limiting, JWT Refresh 토큰 회전 | ✅ |
| **알림** | 인앱 알림(드롭다운, 읽음/안 읽음), Webhook 이벤트 큐, 예약 발송 | ✅ |
| **관리자** | 별도 어드민 패널(`/admin`), TOTP 2FA + WebAuthn(Passkey) 다중 인증, 복구 코드 | ✅ |

### 3.2 기술적 깊이

| 항목 | 설명 |
|---|---|
| **동시성 안전성** | 경매 입찰·후원 결제에 `SELECT ... FOR UPDATE` 트랜잭션 락 적용 — 동시 입찰 시 race condition 방지 |
| **차순위 낙찰 이전** | 낙찰자 미결제 시 차순위 입찰자에게 자동 이전(최대 2회) → 거절 또는 실패 시 재경매 자동 등록. 공정 거래 + 매출 손실 최소화 |
| **런타임 설정 변경** | `system_settings` 테이블 + 캐시 무효화 — 블루버드 환율, 정산 주기, 수수료율 등을 **무중단 변경** |
| **어댑터 패턴 일관성** | 결제(Stripe), 스토리지(S3/로컬), 이메일(Resend/Mock), KYC(Toss/Stripe Identity), 배송(Aftership 예정) 모두 `{base, mock, real, factory}` 동일 구조 — 환경변수 한 줄로 mock↔real 전환 |
| **마이그레이션 정합성** | Alembic으로 5개 메이저 + 다수 패치 마이그레이션, 모두 **additive**(기존 데이터 보존, 다운그레이드 가능) |
| **다국어·다통화** | i18n 키 기반 한·영 동시 운영, 사용자별 언어 설정, 통화 변환 서비스 |
| **확장성** | Docker Compose 단일 호스트 운영 → Kubernetes 전환 가능한 12-factor 구조, Redis 기반 세션·캐시 분리 |

## 4. 사업성

### 4.1 시장 근거

- **Saatchi Art 모델 검증**: 온라인 단독 갤러리가 글로벌 오프라인 대형 갤러리 3~4개 합산보다 큰 거래량을 만든 선례 — 신진 작품의 온라인 거래 시장이 확장 가능함을 입증
- **신진 미술품 가격대(12만 원~3,000만 원)**는 일반 소비자가 진입 가능한 가격 — 주거 환경 변화(자기 집 그림 1점 설치 트렌드)와 결합 시 수요 확장 여지 큼
- **AI 시대 콘텐츠 진정성** 요구 증가 → 인간 창작자 작품의 가치 재평가 흐름과 정합

### 4.2 다층 수익 모델

| 수익원 | 단위 | 비고 |
|---|---|---|
| **거래 수수료** | 경매·즉시구매 GMV의 % | Order/Settlement 모델로 자동 계산·정산 |
| **후원 수수료** | 블루버드 후원금의 % | 일회성·월 정기 모두 적용 |
| **정기 구독(B2C)** | 컬렉터 연 회비(예: 연 10만 원) | 인덱스 열람·우선 입찰 권한 등 부가 혜택과 결합 |
| **보증금** | 입찰 시 1만 원 환급식 보증금 | 허수 입찰 방지 — 입찰 신뢰도 확보 |
| **B2B 리포트(로드맵)** | 학교·갤러리·후원사 월간 리포트 구독 | 작가 인덱스·트렌드·랭킹 데이터 |
| **결제·환전 마진(추후)** | 다중 통화 거래 시 스프레드 | Stripe Tax + FX 어댑터 |

### 4.3 단계별 KPI 가설 (그로스해킹 깔대기 기반)

| Stage | 지표 | 의미 |
|---|---|---|
| 1. SNS 사용자 | DAU/MAU, 가입자 수 | 깔대기 입구 확장 |
| 2. 후원자 | 후원 전환율(가입자 → 1회 이상 후원), ARPPU | 1차 매출 발생 |
| 3. 컬렉터 | 입찰 참여자 수, GMV, 평균 거래액 | 핵심 매출 |
| 4. B2B | 파트너 학교·갤러리 수, 리포트 구독 ARR | 안정적 매출원·확장성 |
| 5. 글로벌 | 국가별 작가·컬렉터 비중, 거래 회랑(작가 국가 → 컬렉터 국가) | 글로벌 가치사슬 형성 |

## 5. 가치

### 5.1 작가에게

- **글로벌 노출** — 가입 즉시 전 세계 사용자에게 작품 공개
- **저비용 매출 진입** — 갤러리 수수료(통상 30~50%) 대비 합리적 수수료 + 후원 채널
- **창작 과정 자체가 자산** — 타임랩스·메이킹 영상도 후원·수익원이 됨
- **신뢰 가능한 결제·정산** — Stripe 연동, KYC, 주간/월간 자동 정산
- **단계적 성장 트랙** — Student → Emerging → Recommended → Popular 뱃지 시스템과 (로드맵) 작가 인덱스로 가시화

### 5.2 컬렉터·후원자에게

- **저장벽 후원** — 1,000원으로도 작가 후원 가능 (Patreon 최저 단가 대비 압도적 낮음)
- **합리적 가격 발견** — 경매를 통한 투명한 가격 결정, 신진 시기 작품 확보 기회
- **익명·공개범위 선택** — 4단계 visibility(전체/작가만/익명/비공개)
- **컬렉션 관리·증명** — 구매 이력·후원 뱃지 + (로드맵) 작가 성장 데이터 추적

### 5.3 학교·갤러리·후원사(B2B)에게

- **신진 작가 발굴 채널** — 학교·장르별 커뮤니티 + 활동 데이터
- **데이터 기반 의사결정** — 거래 활동·랭킹·트렌드 리포트
- **CSR/후원 효과 측정** — 후원사 리포트로 후원 영향력 가시화

### 5.4 사회적 가치

- **개발도상국 신진 작가의 경제적 자립** 모델 — 사례: "남미 페루 대학생, 그림 1점 후원·낙찰로 1,200만 원 수익" (당사 콘셉트 시나리오)
- **AI 시대 인간 창작자의 가치 재발견** — 인덱스·후원 활동 기반 정량 평가 인프라
- **글로벌 미술 접근성 확대** — 갤러리 부재 지역의 미술 인구 결집

## 6. 차별점

### 6.1 경쟁 비교

| 비교 축 | Instagram | Saatchi Art | Patreon | **Domo** |
|---|:---:|:---:|:---:|:---:|
| SNS 피드·창작 영상 | ✅ | ⚠️ 약함 | ⚠️ | ✅ |
| 작품 거래(경매·즉시구매) | ❌ | ✅ | ❌ | ✅ |
| 마이크로 후원(저장벽) | ❌ | ❌ | ⚠️ 단가 큼 | ✅ (1,000원) |
| 월 정기 후원 | ❌ | ❌ | ✅ | ✅ |
| 작가 심사·등급 | ❌ | ⚠️ 부분 | ❌ | ✅ |
| 미성년자·GDPR 컴플라이언스 | ⚠️ | ⚠️ | ⚠️ | ✅ 내재화 |
| 신진 작가 글로벌 발굴 인덱스(B2B) | ❌ | ❌ | ❌ | ✅ (로드맵) |
| 다크 갤러리 감성 UI | ❌ | ⚠️ | ❌ | ✅ 두쫀쿠 |
| **수익 깔대기(SNS→후원→경매→B2B)** | ❌ | ❌ | ❌ | **✅ 단일 플랫폼** |

### 6.2 7가지 핵심 차별 요인

1. **단일 플랫폼 통합 깔대기** — SNS·후원·경매·B2B를 하나의 사용자 그래프 위에서 운영. 사용자→매출 전환 비용이 경쟁 플랫폼 대비 구조적으로 낮음.
2. **마이크로 후원(1 블루버드 = 1,000원)** — Patreon 최저 단가($1~$5) 대비 진입장벽 대폭 완화. 일반인도 후원자가 됨.
3. **타깃 차별화** — 선진국·기존 갤러리 작가가 아닌 **개발도상국 신진 작가 우선**. 경쟁이 비어 있는 시장.
4. **가격 디스커버리 메커니즘** — 영국식 경매 + 즉시구매 + 차순위 이전 + 보증금 — 신진 시장 특유의 가격 불확실성을 시스템이 흡수.
5. **콘텐츠 신뢰성 인프라** — 작가 심사, 디지털 아트 수동 판독, 3진 아웃 모더레이션, 신고·이의제기 플로우, KYC. **거래 가능한 SNS**로 만드는 차별점.
6. **Production-grade 컴플라이언스** — GDPR, 미성년자 보호자 동의, 정책 버전 추적, JWT Refresh 회전, Rate limiting을 **출시 시점부터 내재화** (Phase 4 완료, 매칭률 97%).
7. **AI 시대 작가 인덱스(로드맵)** — 거래·후원·창작 활동 기반 정량 작가 가치 측정 시스템. 학교·갤러리·후원사 대상 B2B 데이터 상품으로 확장 가능 — **지금 시장에 존재하지 않는 카테고리**.

## 부록 A — 한 단락 요약 (Pitch용)
