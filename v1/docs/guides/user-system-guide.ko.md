## 1. Domo 소개

Domo는 갤러리 입점이 어려운 신진 작가, 미술학도, 동남아·라틴아메리카·동유럽 지역 작가를 위한
**SNS + 블로그 + 작품 쇼케이스 + 후원(Blue Bird) + 경매**를 통합한 플랫폼입니다.

### 핵심 가치
- **Blue Bird 후원**: 진입 장벽이 낮은 마이크로 패트로니지 (월 ₩1,000부터)
- **글로벌 작가 인덱스**: 거래 활동 기반 신진 작가 자동 랭킹
- **AI 보조 큐레이션**: AI 캡션·도슨트·자동 컬렉션으로 작가 정체성 강화
- **다국어 자동 번역**: 한국어로 작성하면 5개 언어로 자동 노출

### 주요 사용자
- **작가**: 작품 게시, 후원 모집, 경매 출품
- **컬렉터**: 작가 발견, 후원, 경매 입찰, 작품 수집
- **팬**: 작가 팔로우, 댓글, 공유, 알림 수신

## 2. 시작하기 — 회원가입 · 로그인 · 프로필

### 2.1 회원가입

3가지 방법을 지원합니다.

| 방법 | 단계 | 비고 |
|------|------|------|
| **이메일 + 비밀번호** | 이메일 인증 → 비밀번호 설정 → 프로필 입력 | 가장 일반적 |
| **소셜 로그인** | Google / GitHub 클릭 → OAuth → 프로필 자동 생성 | 즉시 가입 |
| **매직 링크** | 이메일 입력 → 받은 메일 링크 클릭 | 비밀번호 불필요 |

**입력 항목**:
- 표시 이름 (display_name)
- 이메일
- (선택) 자기소개 (bio) — 5개 언어 자동 번역
- (선택) 지역 (country_code) — Featured Artist 다양성 보정에 활용
- (선택) 주력 장르 — 글로벌 작가 인덱스에 활용

### 2.2 로그인

- 이메일 + 비밀번호
- 소셜 로그인 (Google/GitHub)
- 매직 링크 (이메일로 받은 1회용 링크)
- 토큰 만료: Access 1시간, Refresh 7일 자동 갱신

### 2.3 프로필 작성

프로필 페이지(`/me`)에서 다음을 관리합니다.

- 아바타 이미지 (presigned URL 직접 업로드)
- 표시 이름, 자기소개
- 지역(국가 코드), 주력 장르
- 외부 링크 (포트폴리오, Instagram 등)
- 후원 페이지 공개 여부
- 알림 설정 (8장 참고)
- 접근성 설정 (9장 참고)

> **자기소개 5개국어 자동 번역**: 한국어로 작성한 bio가 영어/일본어/중국어/스페인어로 자동 번역되어
> 해당 locale 사용자에게 노출됩니다. (Phase 7 G'-1 + Phase 9 L-F translation cache)

## 3. 작품 게시 — 포스트 · 시리즈 · AI 캡션 · 도슨트

### 3.1 포스트 작성

`/posts/new`에서 작품을 게시합니다.

**기본 입력**:
- 제목, 본문 (마크다운 지원)
- 미디어 업로드: 이미지(JPG/PNG/WebP/AVIF) · 영상(MP4) · GIF
  - 단일/다중/멀티파트 업로드 지원 (Presigned URL)
  - 최대 10MB/파일, 영상은 최대 100MB
- 장르 태그 (회화·디지털·조각·사진 등)
- 위치 / 촬영지 (선택)
- 공개 범위 (publish controls):
  - **public**: 누구나 열람
  - **followers_only**: 팔로워만
  - **subscribers_only**: 후원자만 (Blue Bird 후원 사용자)
  - **private**: 본인만

**고급 옵션**:
- 시리즈에 추가 (3.3)
- 가격 설정 (product post → 경매 또는 즉시 구매)
- 워터마크 자동 적용 (서명 이미지)
- 이미지 편집 (Konva 기반 인라인 에디터)

### 3.2 AI 캡션 자동 생성 (Phase 9 K-3)

작품 업로드 직후 AI가 자동으로 한국어 캡션을 생성하고 5개 언어로 번역합니다.

- 자동 적용 위치: `<img alt="...">` 자동 채움 → 접근성 + SEO 개선
- 수동 오버라이드: 작가가 직접 캡션 작성 시 AI 캡션을 무시 (`caption_override` 우선)
- 재생성: 작가 요청 시 재생성 가능 (일 3회 제한)
- LLM 미가용 시: 빈 alt + WARNING 로그 (graceful)

### 3.3 시리즈

작품을 주제별로 묶어 일관된 컬렉션으로 노출합니다.

- 시리즈 생성: `/posts/new` → "시리즈 추가" 또는 `/me/series`
- 드래그 앤 드롭으로 순서 변경 (dnd-kit)
- 시리즈별 페이지 (`/users/[id]/series`)
- 시리즈 표지 이미지 자동 또는 수동 지정

### 3.4 AI 도슨트 (작품 해설, Phase 9 K-5)

작가 본인의 해설(`artist_docent_text`) + AI 보조 해설(`ai_docent_text`)이 함께 노출됩니다.

**작가 직접 작성**:
- `/posts/[id]/edit`에서 도슨트 텍스트 입력
- 작품 의도, 영감, 기법 등 자유롭게 서술

**AI 도슨트 생성**:
- "AI 도슨트 생성" 버튼 클릭 → LLM이 작품 + 작가 bio + 시리즈 컨텍스트 분석 → 큐레이터 톤의 해설 생성
- 5개 언어 자동 번역 (translation cache 재사용으로 비용 절감)
- **opt-out 토글**: AI 도슨트 비활성화 가능 (작가 의도 존중)

**노출 우선순위**:
1. 작가 도슨트가 있으면 우선 표시
2. AI 도슨트는 "AI 도슨트 보기" 토글로 펼침
3. opt-out=true 시 AI 섹션 완전 비노출

## 4. 작가 후원 — Blue Bird 시스템

Domo의 핵심 기능. 갤러리 없이도 작가가 직접 후원을 받는 마이크로 패트로니지.

### 4.1 후원 시작

작가 프로필 또는 작품 상세에서 "🐦 Blue Bird 후원" 버튼을 클릭합니다.

**티어 선택**:
- 월 ₩1,000 / ₩5,000 / ₩10,000 / ₩50,000 / 자유 입력
- 작가가 직접 티어 메시지 / 보상 / 공개 범위 설정 가능
- 티어별 보상: 후원자 전용 작품 열람, 시리즈 우선 알림, 직접 메시지 등

**다중 통화 (Phase 8 B'-1)**:
- KRW · USD · JPY · EUR 등 7개 통화 자동 환산
- Open Exchange Rates 일 1회 환율 갱신
- 결제는 Stripe 처리 (USD 기반, 환율로 표기)

### 4.2 결제 · 자동 갱신

**Stripe SetupIntent** 기반 카드 등록:
- PCI-DSS 준수 (Domo 서버는 카드 정보 저장 안 함)
- 익월 자동 갱신 (구독 모델)
- 자동 갱신 ON/OFF 토글 가능

**자동 갱신 알림 (Phase 8 B'-4)**:
- 만료 7일 전 이메일 + 푸시 알림
- 만료 30일 전 사이드바 배너 ("⏰ 곧 만료")
- "갱신하기" 버튼 1클릭으로 즉시 +30일 연장

### 4.3 후원 관리 (`/me/sponsorships`)

내가 후원 중인 작가 목록 + 만료일 + 자동 갱신 상태를 확인합니다.

- 만료 임박 배너 (≤7일 남음)
- 갱신 / 일시 정지 / 해지 버튼
- 결제 이력 다운로드 (PDF / CSV)
- 환불 요청 (단, 7일 이내 + 미사용 작품에 한함)

### 4.4 작가 페이지 — 후원 받기

작가는 `/me/patronage`에서 후원 통계 + 정산 내역을 확인합니다.

- 누적 후원자 수, 월간 활성 후원자 (MAU)
- 코호트 분석 (Phase 8 G''-4: D7/D30 retention)
- Stripe Connect 정산 자동화 (KYC 승인 후)
- 정산 임계값 도달 시 Slack 자동 알림 (Phase 8 H')

## 5. 경매 — 입찰 · 알림 · 결제

작가가 작품을 경매로 출품하면, 컬렉터가 입찰합니다.

### 5.1 경매 출품 (작가)

`/posts/new` → "경매로 출품" 옵션:
- 시작가 (reserve_price)
  - **AI 가격 추천 (Phase 11 예정)**: 비교 작품 + 시장 데이터 기반 자동 제안
- 입찰 단위 (예: ₩10,000)
- 종료 일시 (UTC 자동 변환)
- 즉시 구매가 (선택)

### 5.2 입찰 (컬렉터)

`/auctions/[id]` 경매 상세 페이지:
- 현재 최고가, 입찰 횟수, 종료까지 남은 시간 (실시간)
- 입찰 버튼 → 카드 등록(Stripe) + 입찰 확정
- D-1시간 카운트다운 (`active_auction_end_at`)
- 입찰 알림 (푸시 + 이메일)

### 5.3 자동 알림 (Phase 4 #11)

경매 종료 1시간 / 6시간 / 24시간 전에 자동 알림:
- 작가에게: "경매 종료 임박" + 공유 카드 자동 생성 (PNG)
- 입찰자에게: "더 높은 입찰이 있습니다" 또는 "낙찰 임박"
- 낙찰 후 작가 + 낙찰자 자동 알림

### 5.4 낙찰 · 결제

- 낙찰자에게 결제 링크 (Stripe Checkout) 발송 — 24시간 이내 결제 의무
- 결제 완료 후 작가에게 정산 (Stripe Connect)
- 낙찰자에게 작품 다운로드 / 배송 안내 (작가가 처리)

## 6. 작가 발견 — 피드 · 컬렉션 · Featured Artist

Domo는 작가 발견을 위한 다양한 채널을 제공합니다.

### 6.1 피드 (`/feed` 또는 `/`)

3가지 알고리즘을 선택할 수 있습니다.

| Algo | 설명 | 적용 |
|------|------|------|
| `default` | 시간순 + 트렌딩 70:30 혼합 | 모든 사용자 기본 |
| `v1` | A-3 personalized score 정렬 | 팔로우 가중치 + engagement |
| `v2` | **K-1 Collaborative Filtering** | ML 추천 (Matrix Factorization) |

**v2 ML 피드 (Phase 9 K-1 + Phase 10 K-2)**:
- 사용자 행동 임베딩(L-A) 기반 협업 필터링
- **Diversity Reranking (K-2)**: 장르 ≥ 3종, 지역 ≥ 2종, 신진작가 부스트 +20% 강제
- Cold start 시 chronological fallback (interaction < 5건)
- Redis 5분 TTL 캐시 (latency ≤ 200ms)

**A/B 테스트 (K-8)**:
- `algo=auto`로 설정 시 PostHog feature flag가 v1/v2 분배 (50:50 권장)
- 사용자별 variant 영속화 (재방문 시 동일 그룹)

### 6.2 AI 큐레이션 컬렉션 (Phase 10 K-7)

`/explore/collections` — Editor's Pick 자동 생성

- 주 1회 (월요일 09:00 UTC) AI가 작품 임베딩 클러스터링 → 주제별 컬렉션 생성
  - 예: "이번 주 신진 페인터", "디지털 아트 신예", "동남아시아 작가"
- 5개 언어 자동 번역 (제목 / 설명)
- 클릭 시 `/explore/collections/[id]` 컬렉션 상세 → 작품 그리드
- 공유 버튼 (소셜 미디어 OG 메타 자동 생성)

### 6.3 Featured Artist (Phase 8 G'-7 + Phase 10 K-4)

홈 / 탐색 페이지 상단에 노출되는 추천 작가.

- **수동 큐레이션**: 관리자가 직접 선정
- **AI 자동 추천 (K-4)**: 매주 월요일 06:00 UTC 자동 5명 후보 → admin 검수 후 publish
  - 선정 기준: artist_index_rank > 80% (신진), engagement 상위 30%, 임베딩 다양성, 후원자 0건 우선

### 6.4 작가 검색 / 인덱스

`/explore` — 다양한 발견 채널:
- 장르별 (회화, 디지털, 조각, 사진 등)
- 지역별 (한국, 동남아, 라틴아메리카 등)
- 신진작가 인덱스 (Phase 6 A-6: 거래 + engagement 기반 자동 랭킹)
- 검색바 (제목 / 작가 이름 / 태그)

### 6.5 외부 콘텐츠 (Phase 9 L-B)

- **RSS auto-fetch**: 외부 매체(블로그/포털)에서 작가 관련 기사 자동 수집 → 작가 프로필에 표시
- **Press Kit (Phase 7 C-2)**: 작가 보도자료 자동 생성 + 외부 링크 OG 미리보기 자동 추출

## 7. 메시징 — DM · 그룹 채팅 · 첨부

### 7.1 1:1 DM (Phase 8 B'-2)

`/me/messages` 또는 작가 프로필의 "메시지" 버튼.

- 텍스트 메시지 (HTML escape 처리)
- 읽음 표시 (`last_message_at`, `read_at`)
- 차단 / 신고 기능
- Rate limit: 5 msg/min/대화

### 7.2 그룹 DM (Phase 9 L-C)

3인 이상의 그룹 대화방.

- 생성: `POST /me/messages/conversations/group` (참여자 ≥ 2명)
- 최대 50인 hard limit
- 역할: admin (생성자) / member
- admin만 참여자 추가/제거 가능
- 메시지 히스토리 보존 (참여자 leave 시 left_at 소프트 삭제)

### 7.3 파일 / 이미지 첨부 (Phase 9 L-C)

- 허용 MIME: image/jpeg, image/png, image/gif, image/webp, application/pdf
- 최대 10MB
- S3 Presigned URL 발급 (15분 유효)
- 첨부 미리보기 (이미지) + 다운로드 링크 (파일)

### 7.4 WebSocket 실시간 (Phase 9 L-C)

`WS /ws/dm?token={jwt}` — 실시간 메시지 푸시
- 새 메시지 즉시 화면 표시 (polling 불필요)
- 30초 heartbeat
- 다중 인스턴스: Redis pub/sub (REDIS_URL 미설정 시 in-memory 단일 pod)
- WebSocket 미연결 시 3초 폴링 fallback

## 8. 알림 · 이메일 다이제스트

### 8.1 푸시 알림 (Phase 8 B'-3)

브라우저 / 모바일 푸시 알림 (FCM / APNs).

**활성화**:
- `/me/settings/notifications`에서 디바이스 등록
- 알림 종류별 ON/OFF 토글:
  - 새 후원자 (작가)
  - 후원 만료 임박 (사용자)
  - 경매 입찰 / 종료 (작가 + 입찰자)
  - 새 메시지 (DM / 그룹)
  - 새 댓글 / 좋아요
  - Featured Artist 선정

### 8.2 이메일 다이제스트 (Phase 8 B'-3)

주 1회 또는 격주 — 사용자가 주기 선택 (`weekly` / `biweekly`).

- 팔로우 작가 신작
- 추천 작가 (Featured Artist)
- 본인 작품 통계 요약 (작가)
- 후원 만료 임박
- AWS SES 발송 + 1x1 픽셀 / 클릭 트래킹 (Phase 9 L-B)

### 8.3 만료 배너 (Phase 7 retention loop)

후원 만료 ≤7일 시 사이드바 사이드바 배너:
- "⏳ @작가명 후원이 N일 후 만료됩니다"
- "갱신하기" / "잊기" 버튼 (잊기 후 7일 cooldown)
- B'-4 자동 갱신 부스터 통합 → 1클릭 +30일

## 9. 접근성 — 단순 모드 · 다국어

### 9.1 단순 모드 (Phase 9 L-E)

`/me/settings/accessibility` → "단순 모드 ON"

활성화 시:
- 폰트 크기 +20%
- 애니메이션 / 트랜지션 0.01ms (prefers-reduced-motion 강제)
- 줄 간격 1.8 (가독성 향상)
- 장식 요소 (`.decorative`) 숨김
- backdrop-blur 제거 (배경 명확)

대상: 인지장애, 난독증, 노안 사용자.

### 9.2 다국어 (5개 언어)

언어 자동 감지 + 수동 변경 가능 (`/me/settings`):
- 한국어 (ko, 기본)
- 영어 (en)
- 일본어 (ja)
- 중국어 간체 (zh)
- 스페인어 (es)

자동 번역 항목:
- 작가 자기소개 (bio)
- AI 캡션 / AI 도슨트
- AI 컬렉션 제목 / 설명
- UI 라벨 (i18n.json 5개)

### 9.3 WCAG AAA 준수 (Phase 9 L-E)

핵심 3페이지(피드 / 게시물 / 경매)에 적용:
- 색상 대비 7:1 이상
- focus-visible 명확 (outline 2px)
- Skip-to-content 링크 (`#main-content`)
- aria-label / aria-describedby 적극 활용
- 키보드 Tab 네비게이션 완전 지원

## 10. 보안 · 개인정보

### 10.1 인증 강화

**일반 사용자**: 이메일 + 비밀번호 + 매직 링크
**관리자 / 작가 (선택)**: 2FA TOTP (Google Authenticator) + WebAuthn (보안 키, 지문)

### 10.2 KYC (Know Your Customer)

후원금 수령(작가) / 큰 금액 결제(컬렉터) 시 신원 확인 필수:
- 본인 사진 + 신분증
- AML 자동 스크리닝 (선택, 외부 서비스)
- 승인 후 정산 활성화

### 10.3 세션 관리

- Access 토큰 1시간, Refresh 7일 자동 갱신
- 다른 기기에서 로그인 시 알림 (이메일)
- 모든 세션 로그아웃 (`/me/security`)

### 10.4 GDPR / 개인정보

- 데이터 다운로드: `/me/privacy/export` → JSON ZIP 발송 (이메일)
- 계정 삭제: `/me/privacy/delete` → 30일 grace period 후 영구 삭제
- 동의 관리: 마케팅 / 분석 / 쿠키 별도 옵트인
- 활동 로그 보존 90일 후 자동 삭제 (cron)

## 12. 자주 묻는 질문 (FAQ)

**Q1. 후원금이 작가에게 언제 정산되나요?**
A. KYC 승인된 작가는 매월 1일 자동 정산 (Stripe Connect). 미KYC 시 정산 보류.

**Q2. AI 도슨트를 끄고 싶어요.**
A. 작품 편집 페이지에서 "AI 도슨트 비활성화" 토글 ON. 기존 AI 도슨트는 숨겨지고, 본인 도슨트만 노출됩니다.

**Q3. 외국 사용자에게 작품이 어떻게 보이나요?**
A. 자기소개 / 작품 캡션 / AI 도슨트는 5개 언어로 자동 번역됩니다. 본문 텍스트는 자동 번역되지 않으며, 한국어 그대로 노출됩니다 (수동 다국어 작성 가능).

**Q4. 경매 종료 직전 입찰이 들어오면 자동 연장되나요?**
A. 종료 5분 이내 새 입찰 시 자동 5분 연장 (anti-snipe). 최대 3회까지.

**Q5. 컬렉션이 매주 자동 생성되는데 작가가 빠지고 싶다면?**
A. `/me/settings/curation`에서 "AI 컬렉션 노출 제외" 토글. 단, 글로벌 작가 인덱스 랭킹에는 영향 없음.

**Q6. 후원 자동 갱신 해지는 어떻게 하나요?**
A. `/me/sponsorships` → 해당 작가 카드 → "자동 갱신 해지". 다음 만료일까지는 정상 후원 유지, 이후 자동 종료.

**Q7. 메시지에 파일 첨부가 안 돼요.**
A. 10MB 초과 또는 허용되지 않는 MIME 타입(예: .exe, .zip)인지 확인하세요. 허용: 이미지(jpg/png/gif/webp), PDF.

**Q8. 단순 모드와 다크 모드를 동시에 쓸 수 있나요?**
A. 네. `/me/settings/accessibility`에서 단순 모드 ON + 다크 모드 ON 동시 적용 가능.
