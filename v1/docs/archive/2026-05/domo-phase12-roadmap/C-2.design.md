# Phase 12 C-2 Design: GitHub OAuth + 매직링크 가입

**작성일**: 2026-05-08
**범위**: GitHub OAuth 로그인/가입 + 매직링크 비밀번호 없는 가입
**alembic revision**: 0086_magic_link_tokens (magic_link_tokens 테이블), 0087_github_id (github_id 컬럼, 선택)
**의존성**: Phase 11 D-3 (alembic 0085_email_password_auth), 기존 Google OAuth 패턴 (`app/api/auth.py`)

## 1. 목표 & AC (Acceptance Criteria)

### 목표

Phase 11 D-3에서 이월한 GitHub OAuth와 매직링크 가입을 구현하여 가입 방법을 4종으로 확대한다.
개발자/기술직 사용자(GitHub 계정 보유자)와 비밀번호 없는 간편 가입을 원하는 사용자 유입 채널 추가.

### OQ 확정 결정

| 항목 | 결정 | 근거 |
|------|------|------|
| GitHub OAuth scope | `read:user + user:email` | 이름/아바타/이메일만 필요. 저장소 접근 불필요 (최소 권한 원칙) |
| 매직링크 만료 | 24시간 | 매직링크 업계 표준. 재요청으로 보완 가능 |
| 매직링크 1회용 | 검증 즉시 무효화 | 토큰 재사용 공격 방지 |
| IP 검증 | 기록 + 불일치 시 경고 (차단 아님) | 동일 Wi-Fi 전환 등 정상 환경에서도 IP 변경 가능. UX 저해 최소화 |
| 이메일 중복: GitHub == Google | 계정 통합 (github_id 추가) | OQ-13 패턴 준용. 동일 사용자가 다중 SNS 연동 |
| 이메일 중복: GitHub == 비밀번호 가입 | 409 + 통합 안내 | 명시적 사용자 동의 필요. 자동 병합 안전하지 않음 |
| 매직링크 cooldown | 5분 | D-3 이메일 인증 재발송 패턴과 동일 |
| magic_link_tokens 저장 방식 | 별도 테이블 (alembic 0086) | users 테이블 컬럼 추가 시 null 컬럼 난립. 토큰 수명 관리 명확 |
| github_id 컬럼 | users 테이블 추가 (alembic 0087) | sns_id는 String이라 BIGINT github_id 별도 관리 권장 |

### AC

1. `POST /auth/sns/github` → GitHub code 교환 → access_token → 사용자 정보 조회 → 가입/로그인 + JWT 반환
2. GitHub 이메일 == Google 이메일 → 계정 통합 (github_id 추가) + 로그인 성공
3. GitHub 이메일 == 비밀번호 가입 이메일 → 409 `GITHUB_EMAIL_CONFLICT` + 통합 안내 메시지
4. `POST /auth/magic-link/request` → 이메일 존재 여부 무관하게 메일 발송 (가입/로그인 분기 내부 처리), 5분 cooldown
5. `POST /auth/magic-link/verify` → 토큰 검증 (24h 만료, 1회용, IP 기록) → 신규: `setup_required: true` + user 반환, 기존: JWT 즉시 발급
6. LoginModal 4 탭: Google / GitHub / 이메일+비번 / 매직링크
7. `app/auth/magic-link/[token]/page.tsx` — 검증 페이지 (신규 사용자 display_name 입력 포함)
8. audit_log: `auth.github_signup`, `auth.github_login`, `auth.magic_link_request`, `auth.magic_link_signup`, `auth.magic_link_login`
9. i18n 5 locale (ko/en/ja/zh/es): `auth.github.*`, `auth.magic_link.*`
10. tsc 0 errors, pytest 10+ 신규 테스트 통과

## 3. GitHub OAuth Endpoint

### 3-1. POST /auth/sns/github

**위치**: `app/api/auth.py` — 기존 `google_login` 패턴 준용

**Request**:
```json
{
  "code": "github_oauth_code_from_frontend",
  "redirect_uri": "https://domo.art/auth/callback/github"
}
```

**비즈니스 로직**:

```python
@router.post("/sns/github")
async def github_login(
    body: GitHubLoginRequest,
    request: Request,
    db: AsyncSession = Depends(get_db),
    _rl=rate_limit("auth_login"),
):
    """GitHub OAuth 로그인/가입.

    1. body.code → GitHub access_token 교환 (POST https://github.com/login/oauth/access_token)
    2. access_token → GitHub API /user + /user/emails 조회 (scope: read:user + user:email)
    3. github_id로 기존 계정 조회
    4. 이메일 중복 처리 (Google 계정 → 통합, 비밀번호 가입 → 409)
    5. 신규: User 생성
    6. audit_log 기록
    7. JWT 발급
    """
    # Step 1: code → access_token
    gh_token = await exchange_github_code(body.code, body.redirect_uri)

    # Step 2: access_token → user info
    gh_user = await fetch_github_user(gh_token)
    github_id: int = gh_user["id"]
    name: str = gh_user.get("name") or gh_user.get("login") or "user"
    avatar: str | None = gh_user.get("avatar_url")

    # GitHub 이메일: primary + verified 우선
    email: str | None = await fetch_github_primary_email(gh_token)
    if not email:
        raise ApiError("GITHUB_EMAIL_REQUIRED", "GitHub 계정에 인증된 이메일이 없습니다.", http_status=400)

    # Step 3: github_id로 기존 계정 조회
    result = await db.execute(select(User).where(User.github_id == github_id))
    user = result.scalar_one_or_none()

    is_new_user = False

    if not user:
        # Step 4: 이메일로 기존 계정 조회
        result = await db.execute(select(User).where(User.email == email))
        existing = result.scalar_one_or_none()

        if existing:
            if existing.role == "admin":
                raise ApiError("ADMIN_SNS_FORBIDDEN", "관리자 계정은 /auth/admin/login을 사용하세요.", http_status=403)

            if existing.sns_provider == "google":
                # Google 계정 → GitHub 통합 (github_id 추가)
                existing.github_id = github_id
                if not existing.avatar_url and avatar:
                    existing.avatar_url = avatar
                await db.commit()
                await db.refresh(existing)
                user = existing
            elif existing.password_hash is not None:
                # 비밀번호 가입 계정 → 409 충돌
                raise ApiError(
                    "GITHUB_EMAIL_CONFLICT",
                    "해당 이메일로 이미 비밀번호 가입된 계정이 있습니다. 로그인 후 계정 연동을 진행해주세요.",
                    http_status=409,
                    extra={"merge_hint": "/settings/security"},
                )
            else:
                # 기타 SNS 계정 (예외적 케이스)
                existing.github_id = github_id
                await db.commit()
                user = existing
        else:
            # Step 5: 신규 사용자 생성
            is_new_user = True
            user = User(
                email=email,
                sns_provider="github",
                github_id=github_id,
                display_name=name,
                avatar_url=avatar,
                role="user",
                status="active",
                email_verified=True,  # GitHub primary+verified 이메일 신뢰
            )
            db.add(user)
            await db.commit()
            await db.refresh(user)

    ua, ip = _client_info(request)
    access, refresh = await issue_initial_tokens(db, user, user_agent=ua, ip_address=ip)
    await db.commit()

    # PostHog 이벤트 (신규만)
    if is_new_user:
        capture_event(str(user.id), "user_signup_confirmed", {"method": "github"})

    # audit_log
    action = "auth.github_signup" if is_new_user else "auth.github_login"
    await record_audit(db, actor=user, action=action, metadata={"ip": ip}, request=request, status="success")

    return {
        "data": {
            "tokens": TokenPair(access_token=access, refresh_token=refresh).model_dump(),
            "user": UserPublic.model_validate(user).model_dump(mode="json"),
        }
    }
```

**GitHub API 헬퍼 함수** (`app/services/github_oauth.py`):

```python
import httpx
from app.core.config import settings

GITHUB_TOKEN_URL = "https://github.com/login/oauth/access_token"
GITHUB_API_BASE = "https://api.github.com"

async def exchange_github_code(code: str, redirect_uri: str) -> str:
    """GitHub OAuth code → access_token 교환."""
    async with httpx.AsyncClient() as client:
        resp = await client.post(
            GITHUB_TOKEN_URL,
            json={
                "client_id": settings.GITHUB_CLIENT_ID,
                "client_secret": settings.GITHUB_CLIENT_SECRET,
                "code": code,
                "redirect_uri": redirect_uri,
            },
            headers={"Accept": "application/json"},
            timeout=10.0,
        )
        resp.raise_for_status()
        data = resp.json()
        if "error" in data:
            raise ApiError("GITHUB_TOKEN_EXCHANGE_FAILED", data.get("error_description", "code 교환 실패"), http_status=400)
        return data["access_token"]

async def fetch_github_user(access_token: str) -> dict:
    """GitHub /user 조회."""
    async with httpx.AsyncClient() as client:
        resp = await client.get(
            f"{GITHUB_API_BASE}/user",
            headers={"Authorization": f"Bearer {access_token}", "Accept": "application/vnd.github+json"},
            timeout=10.0,
        )
        resp.raise_for_status()
        return resp.json()

async def fetch_github_primary_email(access_token: str) -> str | None:
    """GitHub /user/emails에서 primary + verified 이메일 반환."""
    async with httpx.AsyncClient() as client:
        resp = await client.get(
            f"{GITHUB_API_BASE}/user/emails",
            headers={"Authorization": f"Bearer {access_token}", "Accept": "application/vnd.github+json"},
            timeout=10.0,
        )
        resp.raise_for_status()
        emails = resp.json()
        for entry in emails:
            if entry.get("primary") and entry.get("verified"):
                return entry["email"]
        return None
```

## 4. 매직링크 Endpoints

### 4-1. POST /auth/magic-link/request

**Request**:
```json
{
  "email": "user@example.com"
}
```

**비즈니스 로직**:

```python
@router.post("/magic-link/request")
async def request_magic_link(
    body: MagicLinkRequest,
    request: Request,
    db: AsyncSession = Depends(get_db),
    _rl=rate_limit("auth_magic_link"),
):
    """매직링크 요청 — 이메일 입력만으로 가입/로그인 링크 발송.

    보안: 이메일 존재 여부를 응답에서 노출하지 않음 (항상 200 반환).
    """
    email = body.email.lower().strip()

    # 1) 5분 cooldown 확인
    result = await db.execute(
        select(MagicLinkToken)
        .where(
            MagicLinkToken.email == email,
            MagicLinkToken.is_used == False,
            MagicLinkToken.created_at > (utcnow() - timedelta(minutes=5)),
        )
        .order_by(MagicLinkToken.created_at.desc())
    )
    recent = result.scalar_one_or_none()
    if recent:
        raise ApiError(
            "MAGIC_LINK_COOLDOWN",
            "매직링크는 5분에 한 번만 요청할 수 있습니다.",
            http_status=429,
            extra={"retry_after_seconds": 300},
        )

    # 2) 토큰 생성
    import secrets
    token = secrets.token_urlsafe(32)
    ip = request.client.host if request.client else None
    expires_at = utcnow() + timedelta(hours=24)

    magic = MagicLinkToken(
        email=email,
        token=token,
        ip_address=ip,
        is_used=False,
        expires_at=expires_at,
    )
    db.add(magic)
    await db.commit()

    # 3) 이메일 발송 (graceful — 발송 실패해도 200 반환)
    magic_link_url = f"{settings.FRONTEND_URL}/auth/magic-link/{token}"
    await send_magic_link_email(email, magic_link_url)  # graceful

    # 4) audit_log
    await record_audit(
        db, actor=None, action="auth.magic_link_request",
        metadata={"email": email, "ip": ip}, request=request, status="success"
    )

    return {"data": {"message": "매직링크를 이메일로 발송했습니다. 24시간 내에 클릭해주세요."}}
```

**Response (200)**:
```json
{
  "data": {
    "message": "매직링크를 이메일로 발송했습니다. 24시간 내에 클릭해주세요."
  }
}
```

**Rate Limit**: `auth_magic_link` 룰 — IP당 10회/시간 (기존 `auth_login` 패턴 참고하여 별도 등록).

### 4-2. POST /auth/magic-link/verify

**Request**:
```json
{
  "token": "token_from_email_link",
  "display_name": "작가이름"
}
```

> `display_name`: 신규 사용자만 필수. 기존 사용자는 null 허용.

**비즈니스 로직**:

```python
@router.post("/magic-link/verify")
async def verify_magic_link(
    body: MagicLinkVerifyRequest,
    request: Request,
    db: AsyncSession = Depends(get_db),
):
    """매직링크 토큰 검증 + 가입/로그인.

    신규 사용자: display_name 필요 → setup_required: true 반환 (2단계)
    기존 사용자: JWT 즉시 발급
    """
    # 1) 토큰 조회
    result = await db.execute(
        select(MagicLinkToken).where(MagicLinkToken.token == body.token)
    )
    magic = result.scalar_one_or_none()

    if not magic:
        raise ApiError("MAGIC_LINK_INVALID", "유효하지 않은 매직링크입니다.", http_status=400)

    if magic.is_used:
        raise ApiError("MAGIC_LINK_USED", "이미 사용된 매직링크입니다.", http_status=400)

    if magic.expires_at < utcnow():
        raise ApiError("MAGIC_LINK_EXPIRED", "만료된 매직링크입니다. 새로 요청해주세요.", http_status=400)

    # 2) IP 검증 (차단 아님, 경고용)
    current_ip = request.client.host if request.client else None
    ip_warning = magic.ip_address and current_ip and (magic.ip_address != current_ip)

    # 3) 이메일로 기존 사용자 조회
    result = await db.execute(select(User).where(User.email == magic.email))
    user = result.scalar_one_or_none()

    is_new_user = not user

    if is_new_user:
        # 신규: display_name 없으면 setup_required 반환
        if not body.display_name:
            return {
                "data": {
                    "setup_required": True,
                    "email": magic.email,
                    "message": "활동 이름을 입력해주세요.",
                }
            }
        # display_name 있으면 가입 완료
        user = User(
            email=magic.email,
            sns_provider=None,
            password_hash=None,
            display_name=body.display_name,
            role="user",
            status="active",
            email_verified=True,  # 매직링크 클릭 자체가 이메일 인증
        )
        db.add(user)
        await db.commit()
        await db.refresh(user)

    # 4) 토큰 무효화 (1회용)
    magic.is_used = True
    await db.commit()

    ua, ip = _client_info(request)
    access, refresh = await issue_initial_tokens(db, user, user_agent=ua, ip_address=ip)
    await db.commit()

    # PostHog 이벤트
    if is_new_user:
        capture_event(str(user.id), "user_signup_confirmed", {"method": "magic_link"})

    # audit_log
    action = "auth.magic_link_signup" if is_new_user else "auth.magic_link_login"
    await record_audit(
        db, actor=user, action=action,
        metadata={"ip": current_ip, "ip_warning": ip_warning},
        request=request, status="success"
    )

    return {
        "data": {
            "tokens": TokenPair(access_token=access, refresh_token=refresh).model_dump(),
            "user": UserPublic.model_validate(user).model_dump(mode="json"),
            "ip_warning": ip_warning,  # 프론트엔드 선택적 경고 표시
        }
    }
```

```
POST /auth/magic-link/verify
  ├── 토큰 존재 확인
  ├── is_used 확인 (1회용)
  ├── expires_at 확인 (24h)
  ├── IP 비교 (경고만)
  ├── 이메일로 기존 사용자 조회
  │   ├── 기존 사용자 → JWT 즉시 발급
  │   └── 신규 사용자
  │       ├── display_name 없음 → setup_required: true 반환
  │       └── display_name 있음 → 가입 + JWT 발급
  └── 토큰 is_used = True
```

**신규 사용자 2단계 플로우**:

```
1. POST /auth/magic-link/verify { token: "..." }
   → { setup_required: true, email: "..." }

2. 프론트엔드: display_name 입력 UI 표시

3. POST /auth/magic-link/verify { token: "...", display_name: "작가이름" }
   → { tokens: {...}, user: {...} }
```

> 주의: 2단계에서 동일 토큰을 재사용하므로 `is_used` 전환은 JWT 발급 직전에 수행.

```typescript
"use client";

export default function MagicLinkPage({ params }: { params: { token: string } }) {
  const [step, setStep] = useState<"verifying" | "setup" | "done" | "error">("verifying");
  const [email, setEmail] = useState("");
  const [displayName, setDisplayName] = useState("");

  useEffect(() => {
    verifyToken(params.token);
  }, [params.token]);

  const verifyToken = async (token: string, displayName?: string) => {
    const res = await apiClient.post("/auth/magic-link/verify", { token, display_name: displayName });

    if (res.data.setup_required) {
      setEmail(res.data.email);
      setStep("setup");
      return;
    }

    // JWT 저장 + 리디렉션
    storeTokens(res.data.tokens);
    setStep("done");
    router.push("/");
  };

  // step === "setup": display_name 입력 폼
  // step === "verifying": 로딩 스피너
  // step === "done": 성공 메시지
  // step === "error": 오류 메시지 + 재요청 링크
}
```

## 6. 보안 검증

### 6-1. GitHub OAuth 보안

| 항목 | 구현 |
|------|------|
| scope 최소화 | `read:user user:email` — 저장소/organization 접근 없음 |
| state 파라미터 | `crypto.randomUUID()` → sessionStorage 저장 → callback에서 검증 (CSRF 방지) |
| code 1회용 | GitHub이 자동 보장 (code 재사용 시 401) |
| admin 계정 차단 | `ADMIN_SNS_FORBIDDEN` 403 반환 |
| access_token 미저장 | 서버에서 사용 후 폐기 (DB 저장 불필요) |

### 6-2. 매직링크 보안

| 항목 | 구현 | 세부 |
|------|------|------|
| 토큰 강도 | `secrets.token_urlsafe(32)` | 43자, 256-bit entropy |
| 만료 | 24시간 (`expires_at` DB 검증) | 서버 시간 기준 UTC |
| 1회용 | `is_used = True` (JWT 발급 직전) | DB 트랜잭션 내 처리 |
| IP 기록 | `ip_address` 저장 | 감사 목적 |
| IP 불일치 | 경고 플래그 반환 (`ip_warning: true`) | 차단 아님 — UX 저해 최소화 |
| cooldown | 5분 (`created_at` 기준) | 이메일 폭탄 방지 |
| 이메일 존재 노출 없음 | 항상 200 반환 | 계정 열거 공격 방지 |
| rate limit | IP당 10회/시간 | `rate_limit("auth_magic_link")` |

### 6-3. 이메일 중복 처리 매트릭스

| 기존 계정 | GitHub 요청 | 처리 |
|-----------|------------|------|
| 없음 | 신규 이메일 | 신규 가입 (github_id 저장) |
| Google (sns_provider=google) | 동일 이메일 | 통합: github_id 추가, 로그인 성공 |
| 비밀번호 가입 (password_hash 있음) | 동일 이메일 | 409 GITHUB_EMAIL_CONFLICT |
| admin | 동일 이메일 | 403 ADMIN_SNS_FORBIDDEN |
