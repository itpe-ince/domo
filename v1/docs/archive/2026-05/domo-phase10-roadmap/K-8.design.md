# Phase 10 K-8 Design — ML A/B 테스트 인프라 (PostHog Feature Flag 통합)

> **Summary**: K-1 ML 피드 v2 출시 후 운영 데이터를 기반으로 v1(룰 기반) vs v2(ML 협업
> 필터링)의 성능을 PostHog Feature Flag `ml_feed_v2` 50:50 A/B 테스트로 비교한다.
> ml_experiment_assignments 테이블로 재방문 일관성을 보장하고, PostHog Insights 내장
> 통계 기능으로 CTR·Precision@10·세션 길이·후원 전환율을 14일 이상 측정한다.
> L-B newsletter_events open rate를 보조 신호로 통합하며, POSTHOG_API_KEY 미설정 시
> graceful fallback(전 사용자 v1, WARNING 로그)으로 서비스 중단 없이 운영한다.

## 1. 목표 & Acceptance Criteria

### 목표

| # | 목표 | 근거 |
|---|------|------|
| 1 | PostHog Feature Flag `ml_feed_v2` 50:50 분배로 A/B 분기 구현 | 통계적 검정 가속 — 표본 크기 동등 확보 (OQ-1) |
| 2 | ml_experiment_assignments 테이블로 사용자 할당 영속화 | 재방문 시 동일 그룹 유지 → 실험 오염 방지 |
| 3 | 4개 핵심 KPI 측정 파이프라인 구축 | Feed CTR / Precision@10 / Session duration / 후원 전환율 |
| 4 | L-B newsletter_events open rate 통합 | 이메일 사용자 행동을 보조 engagement 신호로 활용 |
| 5 | PostHog Insights 내장 통계 분석 활용 | 별도 외부 도구 없이 p < 0.05 기준 검정 (OQ-10) |
| 6 | POSTHOG_API_KEY 미설정 시 graceful fallback | 전 사용자 v1 + WARNING 로그 → 서비스 중단 없음 |
| 7 | Prometheus metric 3개 노출 | ml_ab_test_assignments_total / ml_ab_test_events_total / ml_ab_test_conversions_total |

### Acceptance Criteria

- [ ] alembic 0080 적용 후 `ml_experiments` + `ml_experiment_assignments` 테이블 생성 확인
- [ ] `GET /api/feed?algo=auto` → Feature Flag 기반 v1/v2 분기 정상 동작 (기존 v1/v2 직접 지정 동작 유지)
- [ ] ml_experiment_assignments 레코드 생성 (사용자별 variant 영속화, 재방문 시 동일 variant 반환)

- [ ] L-B newsletter open rate → K-8 보조 지표 통합 확인 (newsletter_events 테이블 활용)
- [ ] POSTHOG_API_KEY 미설정 → 전 사용자 v1 + WARNING 로그 동작 확인
- [ ] `GET /api/admin/experiments` admin 전용 권한 검증 (non-admin 403 Forbidden)
- [ ] Prometheus `ml_ab_test_assignments_total` metric 수집 확인
- [ ] unit tests: `tests/unit/test_ml_experiments.py` 통과
- [ ] integration tests: `tests/integration/test_admin_experiments.py` 통과

| A/B 분배 균형 | 50:50 ± 2% | ml_experiment_assignments 집계 |

## 2. Architecture

### 전체 데이터 플로우

```
사용자 요청
    │
    ▼
GET /api/feed?algo=auto
    │
    ▼
posts.py: _resolve_ml_algo_with_experiment()
    │
    ├─ ml_experiments 테이블 조회 → 'feed_v2_rollout' running 실험 없음
    │   └─ algo=v1 (default, graceful)
    │
    └─ running 실험 있음
        │
        ├─ ml_experiment_assignments 조회 (기존 할당 확인)
        │   └─ HIT → variant 반환 (재방문 일관성 보장)
        │
        └─ MISS → posthog_client.get_feature_flag('ml_feed_v2', user_id)
            │
            ├─ POSTHOG_API_KEY 미설정 → Mock 모드 → variant='v1' + WARNING
            │
            └─ flag ON(treatment) / OFF(control) → variant 결정
                │
                └─ ml_experiment_assignments INSERT (영속화)
                    │
                    └─ Prometheus ml_ab_test_assignments_total +1
                        │
                        ▼
                    ┌─ variant = 'v2' ─────────────────────────┐
                    │  ml_feed_inference.get_recommendations()   │
                    │  (K-1 Collaborative Filtering)             │
                    └────────────────────────────────────────────┘
                    ┌─ variant = 'v1' ─────────────────────────┐
                    │  _personalized_feed_v1() / chronological   │
                    └────────────────────────────────────────────┘
                        │
                        ▼
                    응답: {data: PostOut[], algo_used: 'v1'|'v2', experiment_variant: ...}
                        │
                        ▼
                    PostHog 이벤트 발화 (비동기, fire-and-forget)
                        feed_post_click / sponsor_created / session_duration
                        │
                        ▼
                    PostHog Insights 대시보드 (A/B 통계 자동 계산)
```

### 이벤트 트래킹 흐름

```
[피드 노출]
  Frontend PostHog.capture('feed_view', { algo_variant: 'v1'|'v2' })

[피드 클릭]
  Frontend PostHog.capture('feed_post_click', { post_id, algo_variant })
  → PostHog Experiment: CTR 분모/분자 자동 집계

[후원 전환]
  Backend POST /api/posts/{id}/sponsor
  → posthog_client.capture('sponsor_created', { algo_variant, ... })
  → Prometheus ml_ab_test_conversions_total +1

[L-B newsletter open]
  기존 newsletter_events 테이블 (L-B 구현) → K-8 보조 집계
  → GET /api/admin/experiments/{name}/results 에 포함
```

### ml_experiment_assignments 영속화 원칙

```
재방문 일관성: 동일 사용자 + 동일 experiment → 항상 동일 variant
원칙:
  1. ml_experiment_assignments 테이블 조회 (UNIQUE: experiment_id + user_id)
  2. 레코드 있음 → 저장된 variant 반환 (PostHog flag 재조회 불필요)
  3. 레코드 없음 → PostHog flag 조회 → DB INSERT → variant 반환
  4. DB INSERT 실패 (race condition) → ON CONFLICT DO NOTHING + 재조회
```

### PostHog 통합 레이어

```
posthog_client.py
│
├─ get_feature_flag(flag_key, user_id) → bool | None
│   ├─ POSTHOG_API_KEY 있음 → posthog-python SDK 호출
│   └─ 없음 → Mock 모드: False 반환 + WARNING 로그
│
└─ capture(event_name, user_id, properties) → None
    ├─ POSTHOG_API_KEY 있음 → posthog.capture() 비동기 호출
    └─ 없음 → log.debug("PostHog Mock: event=%s", ...) + 무시
```

## 4. Service Layer

### 4-1. `app/services/ml_experiments.py` (신규)

```python
"""ML A/B 테스트 서비스 — Phase 10 K-8.

주요 기능:
  - get_user_variant(): 사용자 variant 조회 또는 생성 (PostHog flag 결과 영속화)
  - record_event(): PostHog 이벤트 발화 + Prometheus metric 갱신
  - cleanup_old_experiments(): 90일 이전 assignments 정리

Mock 모드:
  - POSTHOG_API_KEY 미설정 → 모든 사용자 v1 + WARNING 로그
  - ml_experiments 테이블에 running 실험 없음 → variant='v1' (default)
"""
from __future__ import annotations

import logging
import os
from datetime import datetime, timedelta, timezone
from typing import Any

from sqlalchemy import text
from sqlalchemy.ext.asyncio import AsyncSession

from app.services.posthog_client import posthog_client

log = logging.getLogger(__name__)

_EXPERIMENT_NAME = os.getenv("ML_AB_EXPERIMENT_NAME", "feed_v2_rollout")
_POSTHOG_FLAG_KEY = os.getenv("ML_AB_FLAG_KEY", "ml_feed_v2")
_DEFAULT_VARIANT = "v1"  # POSTHOG_API_KEY 미설정 시 전 사용자 v1


async def get_user_variant(
    db: AsyncSession,
    experiment_name: str,
    user_id: str,
) -> str:
    """사용자의 실험 variant 반환. 없으면 PostHog flag 조회 후 DB 영속화.

    반환: 'v1' 또는 'v2'
    우선순위:
      1. ml_experiment_assignments 기존 레코드 (재방문 일관성)
      2. PostHog feature flag 조회 (신규 할당)
      3. Mock fallback → 'v1' (POSTHOG_API_KEY 미설정)
    """
    # 1. 실험 조회
    exp_result = await db.execute(
        text("""
            SELECT id FROM ml_experiments
            WHERE name = :name AND status = 'running'
            LIMIT 1
        """),
        {"name": experiment_name},
    )
    exp_row = exp_result.fetchone()
    if exp_row is None:
        log.debug("get_user_variant: running 실험 없음 ('%s') → v1 default", experiment_name)
        return _DEFAULT_VARIANT

    experiment_id = str(exp_row.id)

    # 2. 기존 할당 확인
    assign_result = await db.execute(
        text("""
            SELECT variant FROM ml_experiment_assignments
            WHERE experiment_id = :exp_id AND user_id = :uid
            LIMIT 1
        """),
        {"exp_id": experiment_id, "uid": user_id},
    )
    assign_row = assign_result.fetchone()
    if assign_row is not None:
        log.debug(
            "get_user_variant: 기존 할당 HIT (user=%s, variant=%s)",
            user_id, assign_row.variant,
        )
        return assign_row.variant

    # 3. PostHog feature flag 조회 → variant 결정
    flag_on = await posthog_client.get_feature_flag(_POSTHOG_FLAG_KEY, user_id)
    variant = "v2" if flag_on else "v1"

    # 4. DB 영속화 (race condition 안전: ON CONFLICT DO NOTHING)
    try:
        await db.execute(
            text("""
                INSERT INTO ml_experiment_assignments (experiment_id, user_id, variant)
                VALUES (:exp_id, :uid, :variant)
                ON CONFLICT ON CONSTRAINT uq_mea_experiment_user DO NOTHING
            """),
            {"exp_id": experiment_id, "uid": user_id, "variant": variant},
        )
        await db.commit()
    except Exception as exc:  # noqa: BLE001
        log.warning("get_user_variant: INSERT 실패 (%s) — variant=%s 반환", exc, variant)
        await db.rollback()

    # Prometheus metric
    _increment_assignments_metric(variant)

    log.info(
        "get_user_variant: 신규 할당 (user=%s, experiment=%s, variant=%s)",
        user_id, experiment_name, variant,
    )
    return variant


async def record_event(
    experiment_name: str,
    user_id: str,
    event_type: str,
    metadata: dict[str, Any] | None = None,
) -> None:
    """PostHog 이벤트 발화 + Prometheus metric 갱신.

    event_type: 'feed_post_click' | 'sponsor_created' | 'session_end' | ...
    비동기 fire-and-forget: 실패해도 응답 지연 없음.
    """
    props = {"experiment": experiment_name, "user_id": user_id}
    if metadata:
        props.update(metadata)

    try:
        await posthog_client.capture(event_type, user_id, props)
        _increment_events_metric(event_type)
        if event_type == "sponsor_created":
            _increment_conversions_metric()
    except Exception as exc:  # noqa: BLE001
        log.warning("record_event: PostHog 발화 실패 (%s)", exc)


async def cleanup_old_experiments(db: AsyncSession, days: int = 90) -> int:
    """90일 이전 ml_experiment_assignments 정리.

    완료된(completed) 실험의 assignments만 삭제.
    running/paused 실험은 보존.
    반환: 삭제된 레코드 수
    """
    cutoff = datetime.now(timezone.utc) - timedelta(days=days)
    try:
        result = await db.execute(
            text("""
                DELETE FROM ml_experiment_assignments mea
                USING ml_experiments me
                WHERE mea.experiment_id = me.id
                  AND me.status = 'completed'
                  AND mea.assigned_at < :cutoff
            """),
            {"cutoff": cutoff},
        )
        await db.commit()
        deleted = result.rowcount
        log.info("cleanup_old_experiments: %d 레코드 삭제 (cutoff=%s)", deleted, cutoff)
        return deleted
    except Exception as exc:  # noqa: BLE001
        log.warning("cleanup_old_experiments: 실패 (%s)", exc)
        await db.rollback()
        return 0


# ── Prometheus metric helpers ─────────────────────────────────────────────────

def _increment_assignments_metric(variant: str) -> None:
    """ml_ab_test_assignments_total{variant=...} +1."""
    try:
        from app.metrics import ML_AB_ASSIGNMENTS
        ML_AB_ASSIGNMENTS.labels(variant=variant).inc()
    except Exception:
        pass  # metrics 미설정 시 무시


def _increment_events_metric(event_type: str) -> None:
    """ml_ab_test_events_total{event_type=...} +1."""
    try:
        from app.metrics import ML_AB_EVENTS
        ML_AB_EVENTS.labels(event_type=event_type).inc()
    except Exception:
        pass


def _increment_conversions_metric() -> None:
    """ml_ab_test_conversions_total +1."""
    try:
        from app.metrics import ML_AB_CONVERSIONS
        ML_AB_CONVERSIONS.inc()
    except Exception:
        pass
```

### 4-2. `app/services/posthog_client.py` (신규)

```python
"""PostHog server-side 클라이언트 — Phase 10 K-8.

posthog-python SDK 통합 (pip install posthog).
POSTHOG_API_KEY 미설정 시 Mock 모드로 동작:
  - get_feature_flag() → False 반환 (전 사용자 v1)
  - capture() → log.debug만 출력, PostHog 미발화
"""
from __future__ import annotations

import logging
import os
from typing import Any

log = logging.getLogger(__name__)

_POSTHOG_API_KEY = os.getenv("POSTHOG_API_KEY", "")
_POSTHOG_HOST = os.getenv("POSTHOG_HOST", "https://app.posthog.com")
_MOCK_MODE = not bool(_POSTHOG_API_KEY)

_posthog_instance = None


def _get_posthog():
    """posthog 인스턴스 lazy 초기화 (import 실패 시 None)."""
    global _posthog_instance
    if _posthog_instance is not None:
        return _posthog_instance
    if _MOCK_MODE:
        return None
    try:
        import posthog as ph
        ph.api_key = _POSTHOG_API_KEY
        ph.host = _POSTHOG_HOST
        _posthog_instance = ph
        log.info("PostHog client 초기화 완료 (host=%s)", _POSTHOG_HOST)
        return ph
    except ImportError:
        log.warning(
            "posthog-python 미설치 — Mock 모드로 전환. "
            "설치: pip install posthog"
        )
        return None


class _PostHogClient:
    """PostHog 클라이언트 래퍼 (Mock 모드 포함)."""

    async def get_feature_flag(self, flag_key: str, user_id: str) -> bool:
        """PostHog feature flag 조회.

        반환: True(v2 treatment) / False(v1 control)
        Mock 모드: False 반환 + WARNING 로그
        """
        ph = _get_posthog()
        if ph is None:
            if _MOCK_MODE:
                log.warning(
                    "PostHog Mock: get_feature_flag('%s', user=%s) → False "
                    "(POSTHOG_API_KEY 미설정)",
                    flag_key, user_id,
                )
            return False
        try:
            result = ph.get_feature_flag(flag_key, user_id)
            enabled = bool(result)
            log.debug(
                "PostHog flag '%s' user=%s → %s",
                flag_key, user_id, "v2" if enabled else "v1",
            )
            return enabled
        except Exception as exc:  # noqa: BLE001
            log.warning("PostHog get_feature_flag 실패 (%s) → False", exc)
            return False

    async def capture(
        self,
        event_name: str,
        user_id: str,
        properties: dict[str, Any] | None = None,
    ) -> None:
        """PostHog 이벤트 발화.

        Mock 모드: log.debug만 출력.
        """
        ph = _get_posthog()
        if ph is None:
            log.debug(
                "PostHog Mock: capture event='%s' user=%s props=%s",
                event_name, user_id, properties,
            )
            return
        try:
            ph.capture(
                distinct_id=user_id,
                event=event_name,
                properties=properties or {},
            )
        except Exception as exc:  # noqa: BLE001
            log.warning("PostHog capture 실패 (event=%s): %s", event_name, exc)


posthog_client = _PostHogClient()
```

# posts.py 변경 부분 — _resolve_ml_algo 확장

async def _resolve_ml_algo_with_experiment(
    algo: str,
    current_user,
    db: AsyncSession,
) -> tuple[bool, str | None]:
    """algo 파라미터 → ML 사용 여부 + experiment_variant 결정.

    반환: (use_ml: bool, variant: str | None)
    - algo=v2: (True, 'v2')
    - algo=v1/default: (False, 'v1')
    - algo=auto: ml_experiments 조회 → get_user_variant() 호출
    """
    if algo == "v2":
        return True, "v2"
    if algo in ("v1", "default"):
        return False, "v1"
    # auto: 실험 기반 분기
    if current_user is None:
        return False, None
    try:
        from app.services.ml_experiments import get_user_variant, _EXPERIMENT_NAME
        variant = await get_user_variant(db, _EXPERIMENT_NAME, str(current_user.id))
        return variant == "v2", variant
    except Exception as exc:  # noqa: BLE001
        log.warning("_resolve_ml_algo_with_experiment 실패 (%s) → v1 fallback", exc)
        return False, "v1"

```sql
-- L-B newsletter open rate: v1/v2 그룹별 집계
SELECT
    mea.variant,
    COUNT(DISTINCT ne.newsletter_id)                          AS newsletters_sent,
    COUNT(DISTINCT CASE WHEN ne.event_type = 'open'
                        THEN ne.newsletter_id END)            AS opens,
    ROUND(
        COUNT(DISTINCT CASE WHEN ne.event_type = 'open'
                            THEN ne.newsletter_id END)::numeric
        / NULLIF(COUNT(DISTINCT ne.newsletter_id), 0) * 100,
        2
    )                                                         AS open_rate_pct
FROM newsletter_events ne
JOIN ml_experiment_assignments mea ON mea.user_id = ne.recipient_user_id
JOIN ml_experiments me ON me.id = mea.experiment_id AND me.name = 'feed_v2_rollout'
WHERE ne.sent_at >= me.started_at
GROUP BY mea.variant;
```
