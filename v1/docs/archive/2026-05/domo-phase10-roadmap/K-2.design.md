# Phase 10 K-2 Design — Diversity Reranking (필터 버블 방지 + 신진작가 부스팅)

> **Summary**: K-1 Collaborative Filtering이 생성한 ML 스코어 상위 100개 후보를 입력으로 받아
> quota-based 다양성 제약(장르 ≥ 3종, 지역 ≥ 2종)과 신진작가 +20% 스코어 부스팅을 적용하여
> 최종 top-20 피드를 재정렬한다. artist_index(Phase 6)를 신진작가 판별 소스로 활용하며,
> 운영 중 튜닝이 가능하도록 `diversity_configs` DB 테이블(alembic 0081)을 제공한다.
> K-1 재학습 없이 기존 스코어를 보정하는 순수 후처리 레이어다.

---

## 1. 목표 & Acceptance Criteria

### 목표

K-1 ML 피드가 특정 장르/지역 작가에 편중되는 필터 버블 현상을 방지하고,
신진 작가(artist_index 기준 상위 80% 이하)의 발견 기회를 늘린다.

| # | 목표 | 이유 |
|---|------|------|
| 1 | 장르 다양성 보장: 피드 top-20 내 장르 ≥ 3종 강제 | 단일 장르 편중으로 신진작가 발굴 기회 상실 방지 |
| 2 | 지역 다양성 보장: 피드 top-20 내 지역 ≥ 2종 강제 | 동남아/남미/동유럽 등 언더-represented 지역 작가 노출 |
| 3 | 신진작가 부스팅: artist_index_rank > 80% 작가에 ×1.20 | README 비전 "전 세계 신진작가 인덱스" 실현 |
| 4 | 운영 중 가중치 튜닝: env 변수 또는 DB config 조정 | 월 1회 튜닝 주기로 운영 데이터 기반 최적화 |
| 5 | K-1 스코어 그대로 활용, 재학습 없음 | 추가 ML 비용 없이 다양성 확보 |
| 6 | artist_index 미가용 시 graceful fallback | Phase 6 의존성 장애 시에도 quota만 적용하여 서비스 정상 동작 |

### Acceptance Criteria

- [ ] alembic 0081 적용 후 `diversity_configs` 테이블 생성 + 초기값 seed 확인
- [ ] `diversity_reranking.rerank()` — 상위 20개에 장르 ≥ 3종 제약 충족 확인
- [ ] `diversity_reranking.rerank()` — 상위 20개에 지역 ≥ 2종 제약 충족 확인
- [ ] 신진작가(artist_index_rank > 80%) 게시물 스코어 ×1.20 적용 확인
- [ ] `ml_feed_inference.get_recommendations()` 마지막 단계에서 `diversity_reranking.rerank()` 호출 확인
- [ ] `DIVERSITY_RERANKING_ENABLED=false` 환경변수 시 reranking 비활성(K-1 결과 그대로 반환) 확인
- [ ] artist_index 데이터 없는 후보 → 부스트 skip + WARNING 로그, quota만 적용 확인
- [ ] 후보 수 < top_k_window(20) 시 모든 후보 그대로 반환 확인
- [ ] `GET /api/admin/diversity-config` — 현재 설정 조회 확인 (admin 전용)
- [ ] `PATCH /api/admin/diversity-config/feed_default` — 설정 수정 후 즉시 적용 확인
- [ ] unit tests: `tests/unit/test_diversity_reranking.py` 전체 통과
- [ ] integration tests: `tests/integration/test_feed_diversity.py` 전체 통과

### KPIs

| 지표 | 목표값 | 측정 방법 |
|------|:------:|----------|
| 신진작가 노출 비율 | ≥ 30% (피드 top-20 중 artist_index_rank > 80%) | Prometheus `diversity_emerging_ratio` |
| 장르 다양성 | 피드 top-20 unique genres 평균 ≥ 3종 | 서버 메트릭 / Shannon entropy ≥ 1.5 |
| 지역 다양성 | 피드 top-20 unique regions 평균 ≥ 2종 | 서버 메트릭 |
| Reranking 추가 레이턴시 | ≤ 20ms | OpenTelemetry 스팬 |
| NDCG@10 저하 | ≤ 5% (K-8 A/B 측정) | PostHog Experiment |
| 사용자 클릭률 delta | K-8 A/B로 v1 vs v2+diversity 비교 | PostHog CTR 이벤트 |

## 2. Architecture

### 파이프라인 개요

```
Client
  │  GET /api/feed?algo=v2
  ▼
posts.py router
  │  _resolve_algo() → use_ml=True
  ▼
ml_feed_inference.get_recommendations(user_id, top_k=100)
  │
  │  [K-1] MF 점수 + pgvector cosine 보정 → 상위 100 후보
  │  (post_id, mf_score, post_metadata) 리스트
  ▼
diversity_reranking.rerank(candidates, post_metadata, config)
  │
  │  1단계: 신진작가 부스팅 (artist_index 조회 → ×1.20)
  │  2단계: quota-based 재정렬 (장르 ≥ 3종, 지역 ≥ 2종 강제)
  │  3단계: 최종 정렬 후 top-20 반환
  ▼
posts.py router
  │  post_ids → _load_posts_by_ids() → PostOut[] 직렬화
  ▼
Client 응답: PostOut[] (형식 동일, 프론트엔드 변경 없음)
```

### 입출력 명세

| 항목 | 상세 |
|------|------|
| 입력 | `list[tuple[str, float]]` — (post_id, final_score) 최대 100개 |
| 보조 메타데이터 | `dict[post_id → PostMeta]` — genre, author_id, author_country_code |
| Config | `DiversityConfig` dataclass (DB 또는 env 기본값) |
| 출력 | `list[str]` — post_id 리스트, top-20 (후보 < 20이면 전체 반환) |

### K-1 ml_feed_inference 수정 범위

기존 `get_recommendations()` 함수는 `top_k=20`으로 호출했으나, K-2 통합 후에는 다음으로 변경된다.

```
top_k=100으로 후보 확장 (reranking pool 확보)
   → diversity_reranking.rerank(candidates=100개, ...) 호출
   → rerank 결과 post_ids 20개 반환
```

Cold user fallback 및 Mock 모드 fallback 경로는 reranking을 거치지 않고 기존과 동일하게 동작한다.

### 환경변수 매트릭스

| 변수 | 기본값 | 설명 |
|------|--------|------|
| `DIVERSITY_RERANKING_ENABLED` | `true` | `false` 시 reranking 비활성, K-1 결과 그대로 반환 |
| `DIVERSITY_EMERGING_BOOST` | `1.20` | 신진작가 스코어 배수 (DB config 없을 시 사용) |
| `DIVERSITY_GENRE_MIN` | `3` | top_k_window 내 최소 unique 장르 수 |
| `DIVERSITY_REGION_MIN` | `2` | top_k_window 내 최소 unique 지역 수 |
| `DIVERSITY_TOP_K_WINDOW` | `20` | 다양성 제약 적용 window 크기 |
| `DIVERSITY_CANDIDATE_POOL` | `100` | K-1에서 가져올 후보 수 (reranking pool) |

## 4. Service Layer

### 4-1. `app/services/diversity_reranking.py` (신규)

```python
"""Diversity Reranking 서비스 — Phase 10 K-2 (필터 버블 방지 + 신진작가 부스팅).

알고리즘: quota-based reranking (MMR은 Phase 11 검토)
  1단계: 신진작가 부스팅 — artist_index_rank > 80% 작가의 post → score × boost
  2단계: quota-based 재정렬 — top_k_window 내 genre ≥ genre_min, region ≥ region_min
  3단계: 최종 score 내림차순 정렬 후 top_k_window 개 반환

Mock 모드:
  - artist_index 없는 후보 → 부스트 skip + WARNING 로그
  - diversity_configs 비어있음 → env 기본값 사용
  - DIVERSITY_RERANKING_ENABLED=false → K-1 결과 그대로 반환
"""
from __future__ import annotations

import dataclasses
import logging
import os
from typing import Any

log = logging.getLogger(__name__)

_ENABLED = os.getenv("DIVERSITY_RERANKING_ENABLED", "true").lower() != "false"
_DEFAULT_BOOST = float(os.getenv("DIVERSITY_EMERGING_BOOST", "1.20"))
_DEFAULT_GENRE_MIN = int(os.getenv("DIVERSITY_GENRE_MIN", "3"))
_DEFAULT_REGION_MIN = int(os.getenv("DIVERSITY_REGION_MIN", "2"))
_DEFAULT_TOP_K = int(os.getenv("DIVERSITY_TOP_K_WINDOW", "20"))
_DEFAULT_POOL = int(os.getenv("DIVERSITY_CANDIDATE_POOL", "100"))

# 신진작가 판별 기준: artist_index_rank 백분위 상위 80% 이하
# artist_index_rank는 1=1위(최상위), 숫자가 클수록 하위권
# "rank > 80%"는 총 아티스트 수 대비 순위가 80% 이상인 경우를 의미
_EMERGING_RANK_PERCENTILE_THRESHOLD = float(
    os.getenv("DIVERSITY_EMERGING_RANK_PERCENTILE", "0.80")
)


@dataclasses.dataclass
class DiversityConfig:
    """다양성 재정렬 설정 dataclass.

    DB diversity_configs 테이블 또는 env 기본값에서 로드.
    """
    name: str = "feed_default"
    emerging_artist_boost: float = _DEFAULT_BOOST
    genre_min_diversity: int = _DEFAULT_GENRE_MIN
    region_min_diversity: int = _DEFAULT_REGION_MIN
    top_k_window: int = _DEFAULT_TOP_K
    candidate_pool_size: int = _DEFAULT_POOL


@dataclasses.dataclass
class PostMeta:
    """재정렬에 필요한 포스트 메타데이터."""
    post_id: str
    genre: str | None          # posts.genre (nullable)
    author_id: str
    author_country_code: str | None   # users.country_code (nullable)
    artist_index_rank: int | None     # users.artist_index_rank (nullable)
    artist_index_total: int | None    # 전체 아티스트 수 (신진작가 판별용)


# ──────────────────────────────────────────────────────────────────────────────
# Config 로드
# ──────────────────────────────────────────────────────────────────────────────

async def load_config(db, config_name: str = "feed_default") -> DiversityConfig:
    """diversity_configs 테이블에서 설정 로드.

    테이블 없거나 레코드 없으면 env 기본값으로 fallback.
    """
    from sqlalchemy import text

    try:
        result = await db.execute(
            text("""
                SELECT
                    name, emerging_artist_boost, genre_min_diversity,
                    region_min_diversity, top_k_window, candidate_pool_size
                FROM diversity_configs
                WHERE name = :name AND status = 'active'
                LIMIT 1
            """),
            {"name": config_name},
        )
        row = result.fetchone()
        if row:
            return DiversityConfig(
                name=row.name,
                emerging_artist_boost=float(row.emerging_artist_boost),
                genre_min_diversity=int(row.genre_min_diversity),
                region_min_diversity=int(row.region_min_diversity),
                top_k_window=int(row.top_k_window),
                candidate_pool_size=int(row.candidate_pool_size),
            )
    except Exception as exc:  # noqa: BLE001
        log.warning("load_config: DB 조회 실패 (%s) — env 기본값 사용", exc)

    log.info("load_config: env 기본값 사용 (name=%s)", config_name)
    return DiversityConfig()


# ──────────────────────────────────────────────────────────────────────────────
# 포스트 메타데이터 일괄 조회
# ──────────────────────────────────────────────────────────────────────────────

async def fetch_post_metadata(
    db,
    post_ids: list[str],
) -> dict[str, PostMeta]:
    """재정렬에 필요한 포스트/작가 메타데이터 일괄 조회.

    posts.genre + posts.author_id + users.country_code + users.artist_index_rank
    단일 JOIN 쿼리로 N+1 방지.
    """
    from sqlalchemy import text

    if not post_ids:
        return {}

    total_result = await db.execute(
        text("SELECT COUNT(*) FROM users WHERE artist_index_rank IS NOT NULL")
    )
    total_artists = int(total_result.scalar_one() or 0)

    placeholders = ", ".join(f"'{pid}'" for pid in post_ids)
    try:
        result = await db.execute(
            text(f"""
                SELECT
                    p.id::text          AS post_id,
                    p.genre             AS genre,
                    p.author_id::text   AS author_id,
                    u.country_code      AS author_country_code,
                    u.artist_index_rank AS artist_index_rank
                FROM posts p
                JOIN users u ON u.id = p.author_id
                WHERE p.id IN ({placeholders})
            """)
        )
        rows = result.fetchall()
    except Exception as exc:  # noqa: BLE001
        log.warning("fetch_post_metadata: DB 조회 실패 (%s) — 빈 메타데이터 반환", exc)
        return {}

    meta: dict[str, PostMeta] = {}
    for row in rows:
        meta[row.post_id] = PostMeta(
            post_id=row.post_id,
            genre=row.genre or "unknown",
            author_id=row.author_id,
            author_country_code=row.author_country_code or "unknown",
            artist_index_rank=row.artist_index_rank,
            artist_index_total=total_artists if total_artists > 0 else None,
        )
    return meta


# ──────────────────────────────────────────────────────────────────────────────
# 신진작가 판별
# ──────────────────────────────────────────────────────────────────────────────

def _is_emerging_artist(meta: PostMeta, total_artists: int) -> bool:
    """artist_index_rank 기준 신진작가 여부 판별.

    신진작가 조건: artist_index_rank / total_artists > EMERGING_RANK_PERCENTILE_THRESHOLD
    즉, 전체 아티스트 중 하위 80% 이하 (순위가 낮을수록 신진)

    artist_index_rank 없으면 False 반환 (부스트 skip).
    """
    if meta.artist_index_rank is None or total_artists == 0:
        return False
    percentile = meta.artist_index_rank / total_artists
    return percentile > _EMERGING_RANK_PERCENTILE_THRESHOLD


# ──────────────────────────────────────────────────────────────────────────────
# 메인 재정렬 함수
# ──────────────────────────────────────────────────────────────────────────────

def rerank(
    candidates: list[tuple[str, float]],
    post_metadata: dict[str, PostMeta],
    config: DiversityConfig,
) -> list[str]:
    """Diversity Reranking — quota-based 알고리즘.

    Args:
        candidates: [(post_id, score), ...] — K-1 추론 결과 (score 내림차순)
        post_metadata: {post_id: PostMeta} — genre, region, artist_index 정보
        config: DiversityConfig — 다양성 제약 파라미터

    Returns:
        list[str] — post_id 리스트, 최대 config.top_k_window개.
                    후보 < top_k_window이면 전체 반환.

    알고리즘:
        1단계) 신진작가 부스팅: artist_index 기준 신진작가 post → score × boost
        2단계) 부스팅 적용 score 내림차순 정렬
        3단계) quota-based 선택:
              - selected 리스트에 순서대로 추가
              - selected 내 unique genres < genre_min → 동일 장르 추가 제한
              - selected 내 unique regions < region_min → 동일 지역 추가 제한
              - top_k_window 채울 때까지 반복
        4단계) quota 조건 미충족 후보 소진 시 나머지 그대로 채움 (graceful)
    """
    if not candidates:
        return []

    # 후보 < window 크기 시 그대로 반환 (graceful)
    if len(candidates) <= config.top_k_window:
        log.info(
            "rerank: 후보 수(%d) ≤ top_k_window(%d) — 전체 반환",
            len(candidates), config.top_k_window,
        )
        return [pid for pid, _ in candidates]

    total_artists = 0
    if post_metadata:
        sample = next(iter(post_metadata.values()))
        total_artists = sample.artist_index_total or 0

    # ── 1단계: 신진작가 부스팅 ──────────────────────────────────────────────
    boosted: list[tuple[str, float]] = []
    boost_applied = 0
    boost_skipped = 0

    for post_id, score in candidates:
        meta = post_metadata.get(post_id)
        if meta is None:
            boosted.append((post_id, score))
            boost_skipped += 1
            continue

        if total_artists > 0 and _is_emerging_artist(meta, total_artists):
            new_score = score * config.emerging_artist_boost
            boosted.append((post_id, new_score))
            boost_applied += 1
        else:
            if meta.artist_index_rank is None:
                boost_skipped += 1
            boosted.append((post_id, score))

    if boost_skipped > 0:
        log.warning(
            "rerank: %d개 후보 artist_index 미가용 — 부스트 skip (quota만 적용)",
            boost_skipped,
        )
    log.info("rerank: 신진작가 부스팅 적용 %d개 / 전체 %d개", boost_applied, len(boosted))

    # ── 2단계: 부스팅 score 내림차순 정렬 ──────────────────────────────────
    boosted.sort(key=lambda x: x[1], reverse=True)

    # ── 3단계: quota-based 선택 ─────────────────────────────────────────────
    selected: list[str] = []
    selected_genres: list[str] = []
    selected_regions: list[str] = []
    deferred: list[tuple[str, float]] = []  # quota 위반으로 미선택된 후보

    for post_id, score in boosted:
        if len(selected) >= config.top_k_window:
            break

        meta = post_metadata.get(post_id)
        genre = meta.genre if meta else "unknown"
        region = meta.author_country_code if meta else "unknown"

        # 현재 selected의 다양성 상태
        unique_genres = len(set(selected_genres))
        unique_regions = len(set(selected_regions))

        # 장르 quota 초과 체크: 이미 genre_min 충족 후에는 동일 장르 허용
        genre_count_in_selected = selected_genres.count(genre)
        genre_quota_ok = True
        if unique_genres < config.genre_min_diversity:
            # 아직 genre_min 미충족 → 이미 있는 장르면 일시 보류
            if genre in set(selected_genres) and genre_count_in_selected >= (
                config.top_k_window // config.genre_min_diversity
            ):
                genre_quota_ok = False

        # 지역 quota 초과 체크: 동일 방식
        region_count_in_selected = selected_regions.count(region)
        region_quota_ok = True
        if unique_regions < config.region_min_diversity:
            if region in set(selected_regions) and region_count_in_selected >= (
                config.top_k_window // config.region_min_diversity
            ):
                region_quota_ok = False

        if genre_quota_ok and region_quota_ok:
            selected.append(post_id)
            selected_genres.append(genre)
            selected_regions.append(region)
        else:
            deferred.append((post_id, score))

    # ── 4단계: quota 조건 미충족으로 보류된 후보로 window 채움 (graceful) ──
    for post_id, _ in deferred:
        if len(selected) >= config.top_k_window:
            break
        selected.append(post_id)

    log.info(
        "rerank 완료: 선택 %d개, unique_genres=%d, unique_regions=%d",
        len(selected),
        len(set(selected_genres[:len(selected)])),
        len(set(selected_regions[:len(selected)])),
    )
    return selected
```

        return cached

    if interaction_count < _COLD_USER_THRESHOLD:

            user_id, interaction_count,

    except Exception as exc:  # noqa: BLE001
        log.warning("get_recommendations: MF 점수 계산 실패 (%s) → fallback", exc)
        return await _chronological_fallback(db, top_k)

    # 5. K-2 Diversity Reranking 적용
    if _DIVERSITY_ENABLED and post_ids_with_scores:
        try:
            from app.services.diversity_reranking import (
                fetch_post_metadata,
                load_config,
                rerank,
            )

                candidates=post_ids_with_scores,
                post_metadata=post_metadata,
                config=config,

                "get_recommendations: diversity reranking 완료 (user=%s, before=%d, after=%d)",

                exc,

## 6. Mock 모드 Fallback

### Fallback 의사결정 트리

```
get_recommendations() 호출
│
├─ DIVERSITY_RERANKING_ENABLED=false
│   → K-1 결과 top_k개 그대로 반환 (reranking 없음)
│
├─ DIVERSITY_RERANKING_ENABLED=true (기본)
│   │
│   ├─ cold user (interaction < threshold)
│   │   → chronological fallback (reranking 미적용)
│   │
│   ├─ ml_models active 없음
│   │   → chronological fallback (reranking 미적용)
│   │
│   └─ MF 점수 계산 성공 → 후보 100개 확보
│       │
│       ├─ diversity_configs 테이블 비어있음
│       │   → env 기본값 DiversityConfig 사용 (정상 진행)
│       │
│       ├─ fetch_post_metadata 실패
│       │   → post_metadata={} 로 rerank 호출
│       │      → 모든 후보 artist_index 없음 → 부스트 skip + WARNING
│       │      → quota-based 정렬만 적용 (장르/지역 메타 없으면 "unknown" 버킷)
│       │
│       ├─ artist_index_rank NULL 후보
│       │   → 해당 post 부스트 skip + WARNING 로그
│       │   → quota-based 정렬은 정상 적용
│       │
│       ├─ 후보 수 < top_k_window
│       │   → 전체 후보 그대로 반환 (graceful)
│       │
│       └─ rerank() 예외 발생
│           → WARNING 로그 + K-1 결과 top_k개 반환 (안전 fallback)
```

### 신진작가 판별 기준 명확화

Phase 6 `artist_index_rank`는 전체 아티스트 중 순위(1=최상위)를 나타낸다.
"신진작가" 정의: `artist_index_rank / total_ranked_artists > 0.80`
즉, 전체 아티스트 중 하위 80% 이하에 위치하는 작가.

artist_index_rank가 NULL인 경우(아직 인덱스 계산 미완료):
→ 신진작가로 간주하지 않음, 부스트 skip + WARNING 로그 기록.
