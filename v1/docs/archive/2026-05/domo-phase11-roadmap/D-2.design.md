# Phase 11 D-2 Design — audit_logs DB 테이블 + Middleware

> **Summary**: 가이드 v1에서 감사 로그 DB 테이블 존재를 공언했으나 실제로는 `log.info("AUDIT action=...")`
> 형태의 구조화 텍스트 로그만 존재한다. 검색·필터·통계·보존이 불가능한 상태를 해제하기 위해
> PostgreSQL `audit_logs` 테이블(alembic 0084)을 신설하고, admin 전 endpoint + sensitive user action
> 4종에 명시적 호출 패턴(`record_audit`)을 적용한다. 보존 기간 1년, 24번째 cleanup worker 등록.

---

## 1. 목표 & Acceptance Criteria

### 목표

| # | 목표 | 근거 |
|---|------|------|
| 1 | audit_logs PostgreSQL 테이블 신설 (alembic 0084) | 텍스트 로그로는 감사 이력 필터·통계 불가 |
| 2 | `record_audit` service 함수 구현 (graceful fail) | main flow 차단 없이 안전한 기록 |
| 3 | admin endpoint 전체 8종 + user sensitive action 4종 적용 | admin 100% 커버 정책 준수 |
| 4 | 1년 보존 cleanup cron (24번째 worker) | 한국 개인정보보호법 요건 내, 운영 이력 충분 |
| 5 | actor_id / action / created_at 인덱스 4개 구성 | 필터·기간 조회 성능 확보 |

### Acceptance Criteria (D-2 종결 조건)

- [ ] `alembic upgrade head` — `audit_logs` 테이블 + 인덱스 4개 생성 확인
- [ ] `record_audit` 호출 시 DB에 행 삽입, actor/action/metadata/ip_address 필드 확인
- [ ] `record_audit` 내부 예외 발생 시 `log.warning` 만 출력되고 main flow 계속 진행 확인
- [ ] `POST /admin/users` 실행 후 audit_logs 행 `action='admin.create_user'` 존재 확인
- [ ] `POST /auth/login` 성공/실패 각각 `status='success'/'failure'` 행 생성 확인
- [ ] `POST /me/delete` 호출 후 audit_logs 행 `action='user.account_delete_request'` 확인
- [ ] audit_log_cleanup_jobs — `created_at < now() - 365d` 행 삭제 확인 (단위 테스트)
- [ ] `AUDIT_LOG_RETENTION_DAYS` env 미설정 시 365일 default 동작 확인
- [ ] tsc 0 errors (프론트엔드 변경 없음), backend pytest 통과

### KPIs

| 지표 | 목표 | 측정 방법 |
|------|:----:|---------|
| admin endpoint audit 커버리지 | 100% | `SELECT DISTINCT action FROM audit_logs WHERE action LIKE 'admin.%'` |
| sensitive user action audit 커버리지 | 4/4종 | login/logout/delete_request/role_change_attempt |
| record_audit graceful fail 보장 | 100% | 예외 시 main flow 중단 없음 (integration test) |

### DDL (PostgreSQL)

```sql
CREATE TABLE audit_logs (
    id            UUID         PRIMARY KEY DEFAULT uuid_generate_v4(),
    actor_id      UUID         NULL REFERENCES users(id) ON DELETE SET NULL,
    -- 행위자 없으면 NULL (system 또는 anonymous)
    actor_role    VARCHAR(20),
    -- 기록 시점 역할: admin / user / artist / system / anonymous
    action        VARCHAR(100) NOT NULL,
    -- 도메인.동사 형식: "admin.create_user", "user.login", "user.account_delete_request"
    target_type   VARCHAR(50),
    -- 영향받은 객체 유형: "user", "post", "auction", "featured_artist_candidate"
    target_id     UUID,
    -- 영향받은 객체 UUID (없으면 NULL)
    metadata      JSONB,
    -- 추가 컨텍스트: before/after 값, 거부 사유, 실험 이름 등
    ip_address    INET,
    user_agent    TEXT,
    status        VARCHAR(20)  NOT NULL DEFAULT 'success',
    -- success / failure / error
    created_at    TIMESTAMPTZ  NOT NULL DEFAULT now()
);

-- 인덱스 4개
CREATE INDEX ix_audit_logs_actor    ON audit_logs (actor_id,   created_at DESC);
CREATE INDEX ix_audit_logs_action   ON audit_logs (action,     created_at DESC);
CREATE INDEX ix_audit_logs_target   ON audit_logs (target_type, target_id);
CREATE INDEX ix_audit_logs_created  ON audit_logs (created_at DESC);
```

### 파일 경로

### 함수 시그니처

```python
from __future__ import annotations

import logging
from uuid import UUID

from fastapi import Request
from sqlalchemy.ext.asyncio import AsyncSession

from app.models.user import User

log = logging.getLogger(__name__)


async def record_audit(
    db: AsyncSession,
    *,
    actor: User | None,
    action: str,
    target_type: str | None = None,
    target_id: UUID | None = None,
    metadata: dict | None = None,
    request: Request | None = None,
    status: str = "success",
) -> None:
    """비동기 audit log 기록.

    실패해도 main flow를 차단하지 않는다 (graceful).
    Request 객체가 전달되면 IP / User-Agent를 자동 추출한다.
    """
    try:
        ip_address: str | None = None
        user_agent: str | None = None
        if request is not None:
            forwarded_for = request.headers.get("x-forwarded-for")
            ip_address = (
                forwarded_for.split(",")[0].strip()
                if forwarded_for
                else (request.client.host if request.client else None)
            )
            user_agent = request.headers.get("user-agent")

        from app.models.audit_log import AuditLog  # 순환 import 방지

        row = AuditLog(
            actor_id=actor.id if actor else None,
            actor_role=actor.role if actor else "system",
            action=action,
            target_type=target_type,
            target_id=target_id,
            metadata=metadata,
            ip_address=ip_address,
            user_agent=user_agent,
            status=status,
        )
        db.add(row)
        await db.commit()
    except Exception as exc:  # noqa: BLE001
        log.warning("record_audit failed (action=%s): %s", action, exc)
```

### 설계 원칙

| 원칙 | 구현 |
|------|------|
| Graceful fail | try/except + log.warning, main flow 계속 |
| IP 자동 추출 | `x-forwarded-for` 우선, 없으면 `request.client.host` |
| 순환 import 방지 | `AuditLog` 모델을 함수 내부에서 lazy import |
| 시스템 행위 | `actor=None` 전달 시 `actor_role='system'` 자동 설정 |
| action 네이밍 | `{domain}.{verb}` 형식 — `admin.create_user`, `user.login` |

### 4-2. User Sensitive Actions (선택 적용)

| endpoint | HTTP | action 값 | status 분기 | 비고 |
|----------|------|-----------|-------------|------|
| `POST /auth/login` | 200/401 | `user.login` | success / failure | 로그인 시도 전체 기록 |

### 구현 패턴 (draft_cleanup_jobs.py 동일 구조)

```python
"""audit_log retention cleanup job — Phase 11 D-2.

Deletes audit_logs rows with created_at < now() - AUDIT_LOG_RETENTION_DAYS days.
Default: 365 days (1년).
Runs daily via the lifespan cron registered in app/main.py (24th worker).
"""
from __future__ import annotations

import asyncio
import logging
import os
from datetime import datetime, timedelta, timezone

from sqlalchemy import delete
from sqlalchemy.ext.asyncio import AsyncSession

from app.db.session import AsyncSessionLocal
from app.models.audit_log import AuditLog

log = logging.getLogger(__name__)

_RETENTION_DAYS = int(os.getenv("AUDIT_LOG_RETENTION_DAYS", "365"))


async def cleanup_old_audit_logs(db: AsyncSession) -> int:
    """AUDIT_LOG_RETENTION_DAYS 이전 audit_logs 행 삭제.

    Returns: 삭제된 행 수.
    """
    cutoff = datetime.now(timezone.utc) - timedelta(days=_RETENTION_DAYS)
    result = await db.execute(
        delete(AuditLog).where(AuditLog.created_at < cutoff)
    )
    deleted = result.rowcount or 0
    if deleted:
        await db.commit()
        log.info(
            "audit_log_cleanup: deleted %d rows older than %d days",
            deleted,
            _RETENTION_DAYS,
        )
    return deleted


async def audit_log_cleanup_cron_loop(interval_seconds: int = 86400) -> None:
    """Background task — 일 1회 실행."""
    log.info(
        "audit_log_cleanup_cron_loop started (interval=%ss, retention=%dd)",
        interval_seconds,
        _RETENTION_DAYS,
    )
    while True:
        try:
            async with AsyncSessionLocal() as db:
                await cleanup_old_audit_logs(db)
        except Exception as e:  # noqa: BLE001
            log.exception("audit_log cleanup cron failed: %s", e)
        await asyncio.sleep(interval_seconds)
```

### main.py 등록

```python
# 24th cron worker — audit_log_cleanup (D-2, 일 1회 86400s)
from app.services.audit_log_cleanup_jobs import audit_log_cleanup_cron_loop

audit_log_cleanup_task = asyncio.create_task(
    audit_log_cleanup_cron_loop(interval_seconds=86400)
)
```

### 모델 정의

```python
from __future__ import annotations

import uuid
from datetime import datetime, timezone

from sqlalchemy import DateTime, String, Text
from sqlalchemy.dialects.postgresql import INET, JSONB, UUID
from sqlalchemy.orm import Mapped, mapped_column

from app.db.base_class import Base


class AuditLog(Base):
    __tablename__ = "audit_logs"

    id: Mapped[uuid.UUID] = mapped_column(
        UUID(as_uuid=True), primary_key=True, default=uuid.uuid4
    )
    actor_id: Mapped[uuid.UUID | None] = mapped_column(UUID(as_uuid=True), nullable=True)
    actor_role: Mapped[str | None] = mapped_column(String(20), nullable=True)
    action: Mapped[str] = mapped_column(String(100), nullable=False)
    target_type: Mapped[str | None] = mapped_column(String(50), nullable=True)
    target_id: Mapped[uuid.UUID | None] = mapped_column(UUID(as_uuid=True), nullable=True)
    metadata: Mapped[dict | None] = mapped_column(JSONB, nullable=True)
    ip_address: Mapped[str | None] = mapped_column(INET, nullable=True)
    user_agent: Mapped[str | None] = mapped_column(Text, nullable=True)
    status: Mapped[str] = mapped_column(String(20), nullable=False, default="success")
    created_at: Mapped[datetime] = mapped_column(
        DateTime(timezone=True), nullable=False, default=lambda: datetime.now(timezone.utc)
    )
```
