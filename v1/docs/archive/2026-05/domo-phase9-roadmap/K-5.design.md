# Phase 9 K-5 Design — LLM 도슨트: 작품 해설

> **Summary**: 작품 상세 페이지에 AI 도슨트(큐레이터 해설) 기능을 추가한다.
> 작가가 직접 작성한 해설(artist_docent_text)과 LLM이 생성한 해설(ai_docent_text)을
> hybrid 방식으로 제공하며, 작가 해설이 항상 우선 노출된다. tuzigroup gemma4-e4b로
> 작품 이미지 + 작가 bio + 시리즈 설명 + 장르 컨텍스트를 분석해 큐레이터 톤의 3~5문단
> 해설을 생성하고, L-F translation_cache를 통해 5 locale 번역을 캐싱한다(alembic 0079).
> 이는 README 비전 "스토리텔링 hub"과 "AI 시대 작가의 정체성 재정의"를 직접 구현한다.

---

## README 비전 연결

> "AI 세상으로 가면 갈수록 예술가들이 제일 먼저 굶어 죽음" — AI를 활용해 작가가 먹고살 수 있는
> 플랫폼 구조 구축.

> "히스토리를 두세 개 만든다" — LLM 도슨트와 AI 캡션으로 작품 스토리텔링 자동화. 언론/SNS 확산 가속.

K-5는 이 두 문장을 가장 직접적으로 구현하는 기능이다. 작가가 콘텐츠 해설에 들이는 시간을 AI가
보조하고, 해설의 품질을 전문 큐레이터 수준으로 끌어올려 컬렉터와 관람자의 작품 체류 시간을 높인다.
K-3(AI 캡션, 1~2문장 검색용)과 달리 K-5는 3~5문단의 예술사적·기법적 맥락 해설을 제공한다.

## 1. 목표 & Acceptance Criteria

### 1-1. 목표

| # | 목표 | 근거 |
|---|------|------|
| 1 | 작가 직접 해설 + AI 도슨트 hybrid 제공 | 작가 자율성 보장 + AI 보조 |
| 2 | 작품 상세 페이지 평균 체류 시간 미적용 대비 ≥ 40% 증가 | 해설이 관람자의 이해와 몰입을 높임 |
| 3 | "AI 도슨트 보기" 클릭률 ≥ 20% (도슨트 생성 포스트 기준) | AI 해설에 대한 사용자 관심 측정 |
| 4 | L-F translation_cache 활용으로 5 locale 번역 중복 호출 차단 | 번역 비용 절감 |
| 5 | AI 생성 명시로 작가 신뢰 보호 | "AI 도슨트 해설 보기" 투명성 문구 |

### 1-2. Acceptance Criteria

- [ ] `posts` 테이블에 4개 컬럼 추가 (alembic 0079 upgrade/downgrade green)
- [ ] `POST /api/posts/{id}/docent/generate` — LLM 호출 → ai_docent_text 저장 (5초 내)
- [ ] `PATCH /api/posts/{id}/docent` — artist_docent_text 저장 (작가 전용)
- [ ] `PATCH /api/posts/{id}/docent/opt-out` — ai_docent_opted_out 토글 (작가 전용)
- [ ] `GET /api/posts/{id}/docent` — artist + ai 도슨트 및 5 locale 번역 반환 (공개)
- [ ] 작가 도슨트 작성 시 AI 도슨트 무시 (artist_docent_text 우선 노출)
- [ ] opt_out=true 시 ai_docent_text가 공개 API에서 null 반환
- [ ] 5 locale 번역: translation_cache hit → LLM 재호출 없음 확인
- [ ] LLM Gateway 미설정 시 ai_docent_text=null + graceful 처리 (에러 없음)
- [ ] 작품 상세 페이지 "AI 도슨트 보기" 토글 UI 동작 확인 (5 locale)
- [ ] 작가 편집 페이지 "AI 도슨트 생성" 버튼 + opt_out 토글 동작 확인
- [ ] 다른 작가의 도슨트 수정/생성 시 403 FORBIDDEN 반환

### 2-3. posts 테이블 추가 컬럼

| 컬럼 | 타입 | 제약 | 설명 |
|------|------|------|------|
| `artist_docent_text` | TEXT | NULL | 작가가 직접 작성한 해설 (우선 노출) |
| `ai_docent_text` | TEXT | NULL | LLM이 생성한 원본 해설 (한국어) |
| `ai_docent_translations` | JSONB | DEFAULT '{}' | 5 locale 번역 캐시 (`{"en": "...", "ja": "...", "zh": "...", "es": "..."}`) |
| `ai_docent_model_version` | VARCHAR(50) | NULL | 생성에 사용된 모델 식별자 (예: gemma4-e4b) |
| `ai_docent_generated_at` | TIMESTAMPTZ | NULL | AI 도슨트 최초 생성 시각 |
| `ai_docent_opted_out` | BOOLEAN | NOT NULL DEFAULT FALSE | 작가가 AI 도슨트를 비활성화한 경우 |

### 2-4. 인덱스

```sql
-- AI 도슨트 생성된 포스트 조회용 (어드민/분석)
CREATE INDEX ix_posts_ai_docent_generated_at
    ON posts (ai_docent_generated_at)
    WHERE ai_docent_generated_at IS NOT NULL;
```

### 2-5. 설계 결정

- `ai_docent_translations` JSONB 선택 이유: locale별 번역은 5개 고정 키로 스파스하며, 별도 테이블보다
  JSONB 단일 컬럼이 JOIN 없이 빠른 조회를 제공한다. L-F의 `translation_cache`가 원본 캐시를 담당하므로
  중복 저장이지만 posts에 denormalize해 쿼리 수를 줄인다.
- `ai_docent_opted_out` DEFAULT FALSE: 신규 포스트는 기본으로 AI 도슨트 활성화 상태. 작가가 명시적으로
  거부해야 비활성화.
- K-3 `caption_text` (1~2문장)와 K-5 `ai_docent_text` (3~5문단)는 목적이 다르므로 별도 컬럼으로 관리.

#### 핵심 함수 시그니처

```python
"""LLM 도슨트 서비스 — K-5 llm-docent-artwork.

작품 이미지 + 작가 bio + 시리즈 설명 + 장르 태그를 조합해 LLM에게 전달하고
큐레이터 톤의 3~5문단 해설(한국어)을 생성한다.

의존성:
  - LLMGatewayClient (app/services/llm_gateway.py) — LLM 호출
  - translation_cache (app/services/translation_cache.py) — 5 locale 번역
  - Phase 6 artist_index 컨텍스트 (user.artist_index_primary_genre 등) 활용

Mock 모드:
  - LLM Gateway 미설정 시 ai_docent_text=None 반환 (예외 없음)
  - translation_cache 미가용 시 한국어 원본만 반환
"""

async def generate_docent(
    db: AsyncSession,
    post_id: uuid.UUID,
    post: Post,
    artist: User,
    series: Series | None,
) -> str | None:
    """AI 도슨트 생성 진입점.

    컨텍스트 조립 → LLM 호출 → DB 저장 → 5 locale 번역 저장.

    Returns:
        생성된 한국어 도슨트 텍스트, 또는 LLM Gateway 미설정 시 None.

    Side effects:
        - post.ai_docent_text 갱신
        - post.ai_docent_translations 갱신 (5 locale)
        - post.ai_docent_model_version 갱신
        - post.ai_docent_generated_at 갱신
    """

def compose_context(
    post: Post,
    artist: User,
    series: Series | None,
) -> str:
    """도슨트 생성용 LLM 프롬프트 조립.

    포함 컨텍스트:
      - 작품 제목, 장르, 태그
      - K-3 AI 캡션 (caption_text — 있는 경우 참고)
      - 작가 bio: display_name, country_code, artist_index_primary_genre
      - 작가 프로필: genre_tags, statement (ArtistProfile)
      - 시리즈 설명: series.title, series.description (있는 경우)

    Returns:
        LLM에 전달할 완성된 프롬프트 문자열.
    """

async def translate_docent_to_locales(
    db: AsyncSession,
    docent_ko: str,
    model_version: str,
) -> dict[str, str]:
    """한국어 도슨트를 4개 locale (en, ja, zh, es)로 번역.

    L-F translation_cache 활용:
      - 캐시 hit → LLM 재호출 없음
      - 캐시 miss → LLM 번역 후 translation_cache 저장

    Returns:
        {"en": "...", "ja": "...", "zh": "...", "es": "..."}
    """
```

#### 프롬프트 설계

```python
_DOCENT_SYSTEM_PROMPT = (
    "You are a professional art museum docent and curator writing in Korean. "
    "Your commentary is scholarly yet accessible — you analyze artworks with "
    "specific references to technique, art history, and emotional resonance. "
    "Avoid marketing language and superlatives. Write 3~5 paragraphs (200~350 words). "
    "Your audience includes collectors, art students, and general viewers."
)

def compose_context(post: Post, artist: User, series: Series | None) -> str:
    genre = post.genre or "미분류"
    tags = ", ".join(post.tags or []) or "없음"
    caption = getattr(post, "caption_text", None) or ""
    artist_name = artist.display_name
    country = artist.country_code or ""
    primary_genre = getattr(artist, "artist_index_primary_genre", "") or genre

    # ArtistProfile에서 statement, genre_tags 조회 (호출부에서 eager load 또는 별도 조회)
    statement = ""   # 호출부에서 ArtistProfile 조회 후 주입
    genre_tags = ""  # 호출부에서 ArtistProfile.genre_tags 조인 후 주입

    series_context = ""
    if series:
        series_context = (
            f"시리즈: {series.title}\n"
            f"시리즈 설명: {series.description or '없음'}\n"
        )

    caption_context = f"AI 캡션 참고 (K-3): {caption}\n" if caption else ""

    prompt = f"""다음 작품 정보를 바탕으로 전문 도슨트 스타일의 해설을 한국어로 작성해 주세요.

---
[작품 정보]
제목: {post.title}
장르: {genre}
태그: {tags}
{caption_context}
[작가 정보]
이름: {artist_name}
국가: {country}
주요 장르: {primary_genre}
장르 태그: {genre_tags}
작가 소개: {statement or '없음'}

{series_context}---

요청 사항:
1. 작품의 예술사적 맥락과 장르적 특성을 1문단으로 서술하세요.
2. 사용된 기법 또는 시각적 특성을 1문단으로 분석하세요.
3. 작품이 전달하는 감정이나 주제를 1문단으로 해석하세요.
4. 선택적으로 작가의 작품 세계와의 연결점을 1문단으로 추가하세요.
5. 관람자에게 감상 포인트를 제안하는 문단으로 마무리하세요.
6. 총 3~5문단, 200~350단어로 유지하세요.
7. "훌륭한", "멋진", "대단한" 같은 마케팅 표현은 사용하지 마세요.
"""
    return prompt.strip()
```

#### generate_docent 구현 흐름

```
generate_docent(db, post_id, post, artist, series) 호출
    ↓
1. opt_out 체크: post.ai_docent_opted_out == True → None 반환 (도슨트 생성 거부)
    ↓
2. 중복 생성 체크: ai_docent_generated_at 24h 이내 → 기존 텍스트 반환 (idempotency)
    ↓
3. compose_context(post, artist, series) → prompt 조립
    ↓
4. LLMGatewayClient().is_mock == True → None 반환 (graceful)
    ↓
5. LLMGatewayClient().generate_interview(prompt, max_tokens=1500, temperature=0.6)
    ↓ 성공
6. docent_ko = result["content"], model_version = result["model"]
    ↓
7. translate_docent_to_locales(db, docent_ko, model_version)
   → translation_cache 활용 (ko→en, ko→ja, ko→zh, ko→es)
    ↓
8. DB 갱신: post.ai_docent_text, ai_docent_translations, ai_docent_model_version, ai_docent_generated_at
    ↓
9. docent_ko 반환
```

## 4. API Endpoints

### 4-1. 엔드포인트 요약

| Method | Path | 권한 | 설명 |
|--------|------|------|------|
| `POST` | `/api/posts/{id}/docent/generate` | 작가 본인 | AI 도슨트 생성 트리거 |
| `PATCH` | `/api/posts/{id}/docent` | 작가 본인 | 작가 직접 해설 작성/수정 |

### 4-2. POST `/api/posts/{id}/docent/generate`

**설명**: 작가가 "AI 도슨트 생성" 버튼 클릭 시 호출. 동기 처리 (max 10초 timeout).

**권한 검사**: `current_user.id == post.author_id` 또는 admin. 불일치 시 403.

**요청**: 본문 없음 (post_id가 path parameter).

**응답 200 OK**:
```json
{
  "ai_docent_text": "이 작품은 후기 인상주의 계열의...",
  "ai_docent_model_version": "gemma4-e4b",
  "ai_docent_generated_at": "2026-05-05T10:00:00Z",
  "ai_docent_translations": {
    "en": "This artwork belongs to the late impressionist...",
    "ja": "この作品は後期印象派の...",
    "zh": "这件作品属于后期印象主义...",
    "es": "Esta obra pertenece al impresionismo tardío..."
  }
}
```

**응답 200 OK (LLM 미설정 Mock 모드)**:
```json
{
  "ai_docent_text": null,
  "message": "AI 도슨트 생성 서비스가 비활성화 상태입니다."
}
```

**응답 409 Conflict** (24h 이내 중복 생성 시):
```json
{
  "error": "DOCENT_RECENTLY_GENERATED",
  "message": "24시간 이내에 이미 생성된 도슨트가 있습니다.",
  "ai_docent_generated_at": "2026-05-05T08:00:00Z"
}
```

**응답 403 Forbidden** (opt-out 상태):
```json
{
  "error": "DOCENT_OPTED_OUT",
  "message": "AI 도슨트가 비활성화 상태입니다. 먼저 활성화해 주세요."
}
```

**비용 안내**: 응답 헤더 `X-Docent-Rate-Limit: 2/day` 포함 (1포스트당 최대 2회/일 제한).

### 4-3. PATCH `/api/posts/{id}/docent`

**설명**: 작가가 직접 도슨트 텍스트를 작성 또는 수정.

**요청 본문**:
```json
{
  "artist_docent_text": "이 작품은 제가 어린 시절 할머니 집 창문에서 본 빛을..."
}
```

**응답 200 OK**:
```json
{
  "artist_docent_text": "이 작품은 제가 어린 시절 할머니 집 창문에서 본 빛을...",
  "updated_at": "2026-05-05T10:05:00Z"
}
```

**비고**: `artist_docent_text` 설정 후 공개 API(`GET /docent`)는 작가 해설을 우선 반환하고,
AI 도슨트는 "AI 도슨트 보기" 토글 시에만 노출.

### 4-4. PATCH `/api/posts/{id}/docent/opt-out`

**설명**: 작가가 AI 도슨트를 완전히 비활성화.

**요청 본문**:
```json
{
  "opted_out": true
}
```

**응답 200 OK**:
```json
{
  "ai_docent_opted_out": true,
  "message": "AI 도슨트가 비활성화되었습니다."
}
```

**비고**: `opted_out=true` 이후 `GET /docent`는 `ai_docent_text: null` 반환.
작가가 재활성화(`opted_out=false`)해도 기존 ai_docent_text는 유지되며 다시 표시된다.

### 4-5. GET `/api/posts/{id}/docent`

**설명**: 공개 도슨트 조회. 인증 불필요.

**쿼리 파라미터**: `?locale=ko|en|ja|zh|es` (기본값: ko)

**응답 200 OK** (작가 해설 있음, AI 도슨트 있음, opt_out=false):
```json
{
  "post_id": "uuid",
  "artist_docent_text": "이 작품은 제가...",
  "ai_docent_text": "이 작품은 후기 인상주의...",
  "ai_docent_opted_out": false,
  "ai_docent_generated_at": "2026-05-05T10:00:00Z",
  "locale_docent": "This artwork belongs to the late impressionist...",
  "locale": "en"
}
```

**locale_docent 결정 로직**:
```
locale=ko → ai_docent_text (원본)
locale=en|ja|zh|es → ai_docent_translations[locale]
                      없으면 → ai_docent_text (한국어 fallback)
                      opt_out=true → null
```

## 7. Mock 모드 Fallback

### 7-1. LLM Gateway 미설정

`LLMGatewayClient.is_mock == True` 시 → `ai_docent_text = None` 반환, 예외 없음.
API 응답: `{"ai_docent_text": null, "ai_docent_translations": {}, "message": "AI 도슨트 생성 서비스가 비활성화 상태입니다."}`

### 7-2. 번역 일부 실패

특정 locale 번역 실패 → 해당 locale을 `ai_docent_translations`에서 제외하고 나머지 저장.
한국어 원본(`ai_docent_text`)은 항상 저장됨. 프론트엔드는 해당 locale 없을 시 한국어 fallback 표시.

### 7-3. 작가 도슨트만 있을 때

- `artist_docent_text` 있음 + `ai_docent_text` 없음 → "작가의 말"만 표시
- AI 도슨트 섹션(토글 버튼) 미노출
- 이 상태가 가장 "작가 중심" 상태

## 11. K-3 vs K-5 차별점 명확화

| 구분 | K-3 AI 캡션 | K-5 LLM 도슨트 |
|------|------------|----------------|
| 길이 | 1~2문장 | 3~5문단 (200~350단어) |
| 목적 | alt text, SEO, 검색 | 감상 해설, 컬렉터 교육 |
| 톤 | 간결·설명적 | 큐레이터·예술비평 |
| 컨텍스트 입력 | 이미지만 | 이미지 + 작가 bio + 시리즈 |
| 작가 입력 | K-3는 없음 | artist_docent_text (병렬) |
| 저장 컬럼 | `caption_text` (0073) | `ai_docent_text` (0079) |
| opt-out | 없음 | `ai_docent_opted_out` |
| 번역 | `caption_translations` | `ai_docent_translations` |
| 생성 제한 | 3회/일 | 2회/일 |

K-3 `caption_text`는 K-5 도슨트 프롬프트에 "AI 캡션 참고"로 포함되어 해설 품질을 높이는 보조 역할을 한다.
