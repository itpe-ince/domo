# Phase 9 K-3 Design — AI 작품 자동 캡션 생성

> **Summary**: 작품 이미지 업로드 시 tuzigroup LLM Gateway(vision 모델, gemma4-e4b)를 호출해
> 자연어 캡션을 자동 생성한다. 생성된 캡션은 `<img alt="">` 접근성(H'-1 booster),
> SEO meta description(H'-3 booster), 작품 상세 보조 설명으로 활용된다.
> 5 locale 번역은 L-F 번역 메모리(translation_cache)를 재사용해 LLM 재호출 없이 처리한다.
> 작가는 AI 캡션을 수동 오버라이드할 수 있으며, `caption_override` 존재 시 AI 캡션은 무시된다.
> API 엔드포인트 3개 추가 + alembic 0078(posts 테이블 확장).

## 1. 목표 & Acceptance Criteria

### 목표

| # | 목표 | 근거 |
|---|------|------|
| 1 | alt text coverage 0% → ≥ 80% (기존 이미지 포스트 기준) | H'-1 WCAG AA 이후 실제 alt text 채우기 미완료 |
| 2 | 업로드 직후 ≤ 5초 이내 캡션 응답 (즉시 호출) | 작가가 편집 화면에서 즉시 결과 확인 가능 |
| 3 | 5 locale 자동 번역 (L-F translation_cache 활용) | LLM 재호출 없이 번역 비용 ↓ |
| 4 | 작가 수동 오버라이드 우선 적용 | AI 캡션이 작가 의도와 다를 경우 편집 가능 |
| 5 | LLM Gateway 미설정 시 graceful fallback (ai_caption=NULL, log only) | CI / 개발 환경에서 ERROR 없이 동작 |
| 6 | batch sweep cron으로 기존 이미지 포스트 캡션 소급 생성 | 신규 업로드 외 기존 작품에도 캡션 커버리지 확보 |

### Acceptance Criteria

- [ ] `posts` 테이블에 5개 컬럼 추가 (alembic 0078 upgrade/downgrade green)
- [ ] `POST /api/posts/{id}/regenerate-caption` → LLM Gateway 호출 → `ai_caption` 저장 확인
- [ ] `PATCH /api/posts/{id}/caption-override` → `caption_override` 저장 + `effective_caption` 반영 확인
- [ ] `POST /api/posts` 이미지 포스트 생성 직후 비동기 캡션 생성 트리거 (백그라운드 태스크)
- [ ] 5 locale 번역 결과 `ai_caption_locale_translations` JSONB에 저장 확인
- [ ] `effective_caption` = `caption_override` (존재 시) 또는 `ai_caption[current_locale]`
- [ ] LLM_GATEWAY_API_KEY 미설정 → `ai_caption=NULL`, 예외 없이 log warning 출력만 확인
- [ ] `quick_sweep_once(batch_size=20)` — 60초 주기, 미생성 작품 처리 확인
- [ ] `batch_sweep_once(batch_size=100)` — 24h 주기, stale 작품(모델 버전 변경) 재처리 확인
- [ ] 21번째 cron worker `artwork_caption_worker` app startup 등록 확인
- [ ] 기존 게시물 CRUD 회귀 없음 (기존 테스트 통과)

### `posts` 테이블 확장

기존 `posts` 테이블에 다음 5개 컬럼을 추가한다. 기존 레코드는 모두 NULL 허용으로 하위 호환을 유지한다.

| 컬럼 | 타입 | 제약 | 설명 |
|------|------|------|------|
| `ai_caption` | TEXT | NULL | LLM 생성 원본 캡션 (한국어, 2~3문장) |
| `ai_caption_locale_translations` | JSONB | DEFAULT '{}' NOT NULL | 5 locale 번역 JSON — `{"en": "...", "ja": "...", "zh": "...", "es": "..."}` |
| `ai_caption_model_version` | VARCHAR(50) | NULL | 캡션 생성에 사용한 LLM 모델 식별자 (예: `gemma4-e4b`) |
| `ai_caption_generated_at` | TIMESTAMPTZ | NULL | 캡션 최초 생성 시각 |
| `caption_override` | TEXT | NULL | 작가 수동 입력 캡션 (이 값이 있으면 AI 캡션 무시) |

#### DDL 요약 (alembic op)

```python
op.add_column("posts", sa.Column("ai_caption", sa.Text(), nullable=True))
op.add_column("posts", sa.Column(
    "ai_caption_locale_translations",
    postgresql.JSONB(astext_type=sa.Text()),
    server_default="{}",
    nullable=False,
))
op.add_column("posts", sa.Column("ai_caption_model_version", sa.String(50), nullable=True))
op.add_column("posts", sa.Column("ai_caption_generated_at", sa.TIMESTAMPTZ(), nullable=True))
op.add_column("posts", sa.Column("caption_override", sa.Text(), nullable=True))
```

#### 인덱스

```sql
-- batch sweep용: ai_caption IS NULL인 이미지 포스트 고속 스캔
CREATE INDEX ix_posts_ai_caption_generated_at
    ON posts (ai_caption_generated_at)
    WHERE ai_caption_generated_at IS NULL;

-- stale 캡션 재생성용: 특정 모델 버전 스캔
CREATE INDEX ix_posts_ai_caption_model_version
    ON posts (ai_caption_model_version)
    WHERE ai_caption_model_version IS NOT NULL;
```

#### 설계 결정

- `ai_caption_locale_translations` JSONB: 5개 locale을 별도 컬럼으로 분리하지 않고 JSONB에 집약해 컬럼 수 최소화. locale 추가 시 schema 변경 불필요.
- `caption_override` 분리: `ai_caption`과 오버라이드를 같은 컬럼으로 쓰면 AI 재생성 시 수동 입력이 덮어씌워짐 — 컬럼 분리로 양쪽 독립 유지.
- `ai_caption_model_version`: 모델 업그레이드 시 이전 버전 캡션을 `WHERE model_version != 'new-model'` 조건으로 일괄 재생성 가능.

## 3. Service Layer

### 3-1. `app/services/artwork_caption_jobs.py` (신규)

**위치**: `v1/backend/app/services/artwork_caption_jobs.py`

#### 핵심 함수 시그니처

```python
async def generate_caption(
    image_url: str,
    locale: str = "ko",
) -> str | None:
    """tuzigroup LLM Gateway vision 모델 호출 → 캡션 텍스트 반환.

    LLM_GATEWAY_API_KEY 미설정(Mock 모드) 시 None 반환, log warning.
    vision 미지원 모델 → 이미지 URL만 전달한 text-only fallback으로 약식 캡션 시도.
    5초 timeout 초과 시 None 반환 (graceful).

    Args:
        image_url: 공개 접근 가능한 작품 이미지 URL.
        locale: 생성 언어 (기본 'ko' 한국어).

    Returns:
        생성된 캡션 텍스트 또는 None (실패/Mock 모드).
    """


async def generate_for_post(
    db: AsyncSession,
    post_id: UUID,
    force: bool = False,
) -> bool:
    """단일 작품 포스트의 캡션 생성 + 5 locale 번역 저장.

    흐름:
      1. posts 테이블에서 post_id, media URL 조회
      2. caption_override가 있으면 AI 캡션 생성 skip (force=True 시 예외)
      3. generate_caption(image_url) 호출
      4. 성공 시 ai_caption, ai_caption_generated_at, ai_caption_model_version 저장
      5. 5 locale 번역: translation_cache.get_cached_translation / save_translation 활용
         (ko → en, ja, zh, es 순, 각 캐시 miss 시 LLM Gateway 번역 호출)
      6. ai_caption_locale_translations JSONB 저장

    Args:
        db: AsyncSession
        post_id: 대상 Post UUID
        force: True 시 caption_override 무시하고 재생성

    Returns:
        True (캡션 생성 성공) / False (실패 또는 skip)
    """


async def quick_sweep_once(
    db: AsyncSession,
    batch_size: int = 20,
) -> dict:
    """ai_caption_generated_at IS NULL인 이미지 포스트를 batch_size개 처리.

    60초 주기 cron에서 호출. 한 번 실행당 최대 batch_size개 처리 후 반환.

    Returns:
        {"processed": int, "succeeded": int, "failed": int}
    """


async def batch_sweep_once(
    db: AsyncSession,
    batch_size: int = 100,
    stale_model_version: str | None = None,
) -> dict:
    """stale 캡션(모델 버전 변경된 작품) 재생성. 24h 주기 cron에서 호출.

    stale_model_version 지정 시: ai_caption_model_version = stale_model_version인 포스트 재생성.
    None 시: ai_caption_generated_at IS NULL인 포스트 처리 (quick_sweep 동일 대상).

    Returns:
        {"processed": int, "succeeded": int, "failed": int}
    """


async def artwork_caption_cron_loop(
    quick_interval_seconds: int = 60,
    batch_interval_seconds: int = 86400,
) -> None:
    """21번째 cron. quick sweep(60s 주기) + batch sweep(24h 주기) 혼합 실행."""
```

#### L-F 번역 메모리 통합

5 locale 번역은 `translation_cache.py`의 기존 함수를 그대로 재사용한다. 재발명 없음.

```python
# artwork_caption_jobs.py 내부 번역 흐름
from app.services.translation_cache import get_cached_translation, save_translation

TARGET_LOCALES = ["en", "ja", "zh", "es"]  # 한국어(ko) 원본 제외

async def _translate_caption_to_all_locales(
    db: AsyncSession,
    ko_caption: str,
    llm_client: LLMGatewayClient,
) -> dict:
    """ko 원본 캡션 → 4 locale 번역 딕셔너리 반환.

    translation_cache 2-tier (Redis → DB) 조회 후 miss 시 LLM Gateway 번역 호출.
    번역 실패 locale은 빈 문자열("")로 기록 (원본 한국어 fallback은 프론트에서 처리).
    """
    translations = {}
    for target_lang in TARGET_LOCALES:
        cached = await get_cached_translation(db, ko_caption, "ko", target_lang)
        if cached:
            translations[target_lang] = cached
        else:
            try:
                translated = await llm_client.translate_text(ko_caption, "ko", target_lang)
                await save_translation(
                    db, ko_caption, "ko", target_lang,
                    translated, llm_client.model,
                )
                translations[target_lang] = translated
            except Exception as e:
                log.warning("caption translation failed ko→%s: %s", target_lang, e)
                translations[target_lang] = ""
    return translations
```

#### effective_caption 로직

```python
def get_effective_caption(post: Post, locale: str = "ko") -> str:
    """caption_override 존재 시 반환. 없으면 locale 번역 또는 ai_caption 반환.

    우선순위:
      1. caption_override (작가 수동 입력)
      2. ai_caption_locale_translations[locale] (locale 번역)
      3. ai_caption (한국어 원본 fallback)
      4. "" (캡션 없음)
    """
    if post.caption_override:
        return post.caption_override
    translations = post.ai_caption_locale_translations or {}
    if locale != "ko" and locale in translations and translations[locale]:
        return translations[locale]
    return post.ai_caption or ""
```

## 4. API Endpoints

### 4-1. `POST /api/posts` 수정 (이미지 포스트 생성 시 비동기 트리거)

### 4-2. `POST /api/posts/{id}/regenerate-caption` (작가 전용, 수동 재생성)

| 항목 | 값 |
|------|-----|
| Method | POST |
| Path | `/api/posts/{id}/regenerate-caption` |
| 권한 | 해당 포스트 작가 (`post.author_id == current_user.id`) |
| 제한 | 1포스트당 3회/일 (rate limit) |

**Request**: Body 없음

**Response** (`200 OK`):
```json
{
  "post_id": "uuid",
  "ai_caption": "수채화 기법으로 표현된 ...",
  "ai_caption_locale_translations": {
    "en": "Expressed in watercolor technique ...",
    "ja": "水彩技法で表現された ...",
    "zh": "以水彩技法表现的 ...",
    "es": "Expresado con técnica de acuarela ..."
  },
  "ai_caption_model_version": "gemma4-e4b",
  "ai_caption_generated_at": "2026-05-05T09:00:00Z",
  "effective_caption": "수채화 기법으로 표현된 ..."
}
```

**오류 응답**:
- `404 Not Found`: 포스트 없음
- `403 Forbidden`: 작가 본인 외 접근
- `429 Too Many Requests`: 일 3회 초과
- `503 Service Unavailable`: LLM Gateway 장애 (fallback: `ai_caption=null` 유지)

### 4-3. `PATCH /api/posts/{id}/caption-override` (작가 수동 입력)

| 항목 | 값 |
|------|-----|
| Method | PATCH |
| Path | `/api/posts/{id}/caption-override` |
| 권한 | 해당 포스트 작가 |

**Request Body**:
```json
{
  "caption_override": "작가가 직접 작성한 캡션 텍스트 (최대 500자)",
  "clear": false
}
```

`"clear": true` 전송 시 `caption_override=NULL` 처리 (AI 캡션으로 복원).

**Response** (`200 OK`):
```json
{
  "post_id": "uuid",
  "caption_override": "작가가 직접 작성한 ...",
  "effective_caption": "작가가 직접 작성한 ..."
}
```

### 4-4. 기존 응답 스키마 확장 (`PostOut`)

`GET /api/posts/{id}`, `GET /api/posts` (피드) 응답에 캡션 관련 필드 추가.

```python
class PostOut(BaseModel):
    # ... 기존 필드 ...
    ai_caption: str | None = None
    ai_caption_locale_translations: dict = {}
    ai_caption_generated_at: datetime | None = None
    caption_override: str | None = None

```

`effective_caption`은 서버에서 계산해 반환. 프론트엔드가 별도 계산 불필요.

### 5-3. locale 자동 표시

현재 사용자 locale(`useLocale()`)에 맞는 번역 캡션 우선 표시. 번역 없으면 한국어 원본 fallback.

```tsx
function getDisplayCaption(post: PostOut, locale: string): string {
  if (post.captionOverride) return post.captionOverride;
  if (locale !== "ko" && post.aiCaptionLocaleTranslations[locale]) {
    return post.aiCaptionLocaleTranslations[locale];
  }
  return post.aiCaption || "";
}
```

`LLM_GATEWAY_API_KEY`, `LLM_GATEWAY_URL`, `LLM_MODEL_NAME`은 기존 Phase 7 C-1 인프라 재사용.

### cron 루프 설계

```python
async def artwork_caption_cron_loop(
    quick_interval_seconds: int = 60,
    batch_interval_seconds: int = 86400,
) -> None:
    """quick sweep(60s)와 batch sweep(24h) 혼합 cron.

    - quick sweep: 미생성 신규 포스트 빠른 처리 (작가 UX)
    - batch sweep: stale 캡션 재생성 또는 야간 대량 소급 처리
    """
    last_batch_at = datetime.min.replace(tzinfo=timezone.utc)

    while True:
        async with AsyncSessionLocal() as db:
            try:
                await quick_sweep_once(db, batch_size=settings.caption_batch_size_quick)

                now = datetime.now(timezone.utc)
                if (now - last_batch_at).total_seconds() >= batch_interval_seconds:
                    await batch_sweep_once(db, batch_size=settings.caption_batch_size_batch)
                    last_batch_at = now

            except Exception as e:
                log.error("[ArtworkCaptionCron] error: %s", e)

        await asyncio.sleep(quick_interval_seconds)
```
